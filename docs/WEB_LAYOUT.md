# 웹 학습 화면 레이아웃

[웹 학습 안내](WEB_GUIDE.md)의 단계별 화면에 적용하는 배치 기준입니다. 현재는 일반적인 PC 모니터에서의 배치를 우선합니다. 작은 화면용 반응형 화면의 전면 개편은 별도 작업입니다. 새 호출어도 같은 공통 레이아웃을 사용하며 특정 호출어나 모델 번호에 따라 배치를 바꾸지 않습니다.

| 영역 | 기준 |
| --- | --- |
| 공통 패널 | 화면 중앙에 배치합니다. 일반 챕터 패널은 최대 760px, 본문은 최대 680px입니다. 기준 목소리 후보와 결과 화면은 각각 필요한 넓은 패널을 사용합니다. |
| 챕터 제목 | 짧은 제목 아래에 해당 단계에서 할 일이나 자동 작업의 목적을 표시합니다. 제목과 부제목은 한 영역으로 묶고 가운데 정렬합니다. |
| 제목·본문·하단 | 영역 사이 간격은 20px입니다. 화면 높이가 560px 이하이면 12px, 발음 검수 화면은 8px입니다. 하단 이동 버튼 높이는 44px입니다. |
| 작업 진행 | 기준 목소리 생성, 호출어·유사어 음성 생성, 증강·특징 추출, 모델 학습, 성능 평가와 결과 정리는 항목명·상태 또는 수량·진행 막대의 공통 행을 사용합니다. 실제 처리량이 없을 때도 대기형 게이지를 표시하며, 실행 중에는 3초 주기의 초록색 회전 아이콘을 표시합니다. 일시정지·오류 상태에서는 아이콘을 멈추고 실제 상태를 알립니다. 실제 수량이 오면 같은 행의 수량형 게이지로 전환합니다. |
| 학습 시작 준비 | 서버의 `training_preparation` 기록이 있을 때 자료 검증·장치 선택·모델 초기화·GPU 자료 적재를 공통 진행 행으로 표시합니다. 확인된 적재량은 KiB·MiB·GiB로 표시합니다. 준비 기록이 없으면 실제 학습 갱신 수를 사용하며, 0회라는 이유로 준비 상태를 추측하지 않습니다. |
| 진행 단계 색인 | 현재 챕터를 고정 강조하지 않습니다. 평소에는 모든 막대를 7px로 표시하며, 마우스를 올리거나 키보드로 초점을 맞춘 위치를 중심으로 36·23·14·7px의 네 단계 길이와 밝기를 적용합니다. 벗어나면 기본 길이로 돌아갑니다. 현재 챕터의 접근성 정보는 별도로 유지합니다. |
| 유사어 문구 | 입력 목록과 저장된 문구 목록은 최대 560px입니다. 높이 44px의 문구 칸을 같은 너비의 두 열과 10px 간격으로 배치합니다. 편집 화면도 본문 높이를 자연스럽게 사용하며 입력칸 내부 영역을 짧게 잘라 스크롤하지 않습니다. 입력 검증과 저장은 하단 다음 버튼으로 진행합니다. |
| 기준 목소리 생성 | 검수 앞에 별도 챕터로 표시합니다. 학습용 후보와 공통 평가용 후보를 공통 진행 행 두 줄로 표시하며, 각 목표는 10분류 × 첫 후보 5개인 50개입니다. 최종 선택 수량을 생성 게이지의 분모로 쓰지 않습니다. 전체 첫 후보가 준비된 뒤 검수 화면을 엽니다. |
| 기준 목소리 검수 | PC 화면에서 패널은 최대 900px, 후보 본문은 최대 820px입니다. 성별·연령 분류마다 후보 카드 5개를 표시하며, 카드에는 실제 옵션과 시드를 표시합니다. 후보 번호는 분류마다 1번부터 시작합니다. 제목 바로 옆에 선택 수량을 강조하고 목표를 채우면 흰색 체크를 표시합니다. 제목 오른쪽은 음량 조절, 카드는 개별 재생 버튼을 사용하며 별도 재생 바나 선택 목록은 만들지 않습니다. 좌우 화살표로 만든 후보를 조회하고 마지막 묶음의 +로 5개를 추가합니다. |
| 후보 추가 생성 | 카드와 생성 안내는 같은 영역에서 전환합니다. `추가 기준 목소리 후보를 생성하고 있습니다...` 바로 오른쪽에 회전 아이콘을 두며 게이지도 즉시 표시합니다. 응답을 기다리는 동안 대기형, 실제 수량을 받은 뒤 수량형으로 바꾸되 본문 높이와 스크롤 위치를 흔들지 않습니다. |
| 음원 듣기 | 호출어 발음 사전 검수·호출어 발음 검수·유사어 발음 검수는 둥근 목록 버튼, 현재 번호와 전체 개수, 둥근 재생 바, 부적합 버튼의 같은 간결한 배치를 사용합니다. 펼친 목록은 PC 화면에서 약 10행까지 보이되 창과 하단 버튼 위의 실제 여유 공간에 맞춰 높이를 제한합니다. 목록을 열거나 닫아도 재생부 위치는 유지하며, 바깥 클릭과 Esc로 닫습니다. |
| 유사어 전체 듣기 | 생성된 음원이 있으면 유사어 발음 확인 화면에서 전체 듣기 대화상자를 엽니다. 선택 목록과 재생 바는 같은 배치를 쓰고 본문은 최대 너비 680px, 최대 높이 220px입니다. 목록 높이는 창 안의 남은 공간에 맞춥니다. |

호출어 입력, 학습 규모 선택, 준비 자료, 다운로드는 각 화면에 맞는 배치를 사용합니다. 초기 로딩과 챕터 이동은 같은 배경과 점 애니메이션을 사용하며, 실제 본문·검수 목록·프레임 높이와 배치가 준비된 뒤 화면을 부드럽게 공개합니다.

학습 결과 정리 중에는 공통 진행 행을 중앙에 표시합니다. 완성된 학습 결과와 마이크 시험은 최대 1060px의 넓은 프레임을 사용합니다. 로컬 Studio의 결과 페이지는 채점한 WAV를 다시 복사하지 않고 검증된 참조로 재생합니다. 휴대 가능한 별도 내보내기는 기본 복사 방식을 유지합니다.

다운로드 목록이 보여도 환경 준비·추출 검증·자료 연결의 현재 작업 안내를 숨기지 않습니다. 이미 저장된 바이트 수를 검사 완료율로 표시하지 않으며, 무결성 검사 중인 파일의 주 게이지는 해당 파일의 검사 진행을 사용합니다.

모델 적재·화자 준비·가속 검사는 처리 속도를 추정하는 구간과 구분합니다. 평가자료 생성은 실제 완료 수량을 표시하고 최종 등록·검증이 끝날 때까지 마무리 상태를 유지합니다. 긴 음원 계산의 활동 정보는 완료 음원 수와 별도 안내로 표시하며, 내부 프레임 수를 저장된 완료 음원 수에 더하지 않습니다.

입력 저장과 기준 목소리의 마지막 분류 승인은 다음 한 번으로 이어집니다. 전환 안내는 저장 성공, 예상한 단계의 완료 근거, 목적 화면 준비를 순서대로 기다립니다. 중간 분류 승인, 실패, 취소와 오래된 응답은 다음 작업을 임의로 시작하지 않습니다.
