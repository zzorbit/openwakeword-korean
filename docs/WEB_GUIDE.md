# 웹 화면에서 한국어 호출어 학습하기

기본 설치를 마친 뒤 `koww web`을 실행합니다. 가상환경을 활성화하지 않았다면 저장소 폴더에서 다음을 사용하세요.

```powershell
.venv\Scripts\python.exe -m korean_openwakeword web
```

Windows 실행 파일은 `scripts/Start-Web.cmd`입니다. 브라우저가 자동으로 열리며 기본 주소는 `http://127.0.0.1:8793/`입니다. 서버를 실행한 터미널은 열어 두세요. 작업 폴더를 직접 고르려면 `koww web --workspace D:\wakeword-work`처럼 지정합니다. 다른 컴퓨터에 서버를 공개하지 않습니다.

## 처음 선택할 것

호출어와 **동작 확인용 / 시험 모델용 / 상용 모델용** 중 하나를 고릅니다. 처음에는 동작 확인용을 권합니다. 수치는 작업량 예시이며 성능을 보장하는 설정이 아닙니다. 세부 설정에서 호출어 수·증강 횟수·학습량·비호출 시간을 바꿀 수 있습니다.

저장 폴더를 비워 두면 작업 폴더의 `projects` 아래에 새 프로젝트를 만듭니다. 같은 작업 폴더의 `shared`와 `cache`는 여러 프로젝트가 재사용합니다. 작업 폴더 밖의 저장 위치를 직접 선택하면 해당 위치 안에 자료·캐시를 둡니다. `.codex`는 선택할 수 없습니다. 기존 프로젝트 폴더를 지정했을 때 호출어와 작업량이 일치하면 원본을 보존하고 연결합니다.

**준비할 자료**에서 출처·이용 조건·다운로드 용량을 확인하고 시작합니다. 학습용 Generic 특징·한국어 음성·AudioSet 일부·FMA·MIT RIR과, 별도 공통 평가용 Seoul·MUSAN·FSD50K·OpenSLR28 자료가 필요합니다. 일부만 선택해 사용해도 원본 묶음 전체를 다운로드해야 할 수 있습니다. Qwen 가중치 용량은 별도이며, 이미 검증한 파일은 재사용합니다.

학습 도구가 없으면 CPU 또는 NVIDIA CUDA 12.8용을 선택해 현재 가상환경에 설치합니다. 전역 Python은 자동 변경하지 않습니다. GPU 드라이버와 선택한 CUDA 배포판의 호환성이 필요하며 설치 실패는 작업 기록에 남습니다.

## 화면에서 진행하는 순서

1. 공개 자료 다운로드·해시 검사·압축 해제·제공자 정보 연결·학습/개발 자료 분리를 진행합니다.
2. 안내된 대표 음원을 듣습니다. 정상 음원은 보존하고 이상한 항목만 표시합니다. 자료 묶음 사용 동의는 전체 원본을 개별 청취했다는 뜻이 아닙니다.
3. 합성 음색과 소량의 단독 호출어를 확인합니다. 동작 확인용의 학습 음색은4계열, 공통 평가 음색은 세 규모 모두30계열이며 파일럿 호출어24개로 시작합니다.
4. 검수 후 선택한 수량의 호출어를 생성합니다. 모든 발화에 독립 STT를 실행하지 않습니다. 유사어 문구는 호출어 자체나 동일 이름이 포함되지 않았는지 화면에서 확인하고, 생성한 대표 발화를 들어봅니다.
5. 승인한 자료로 소음·울림 증강과 특징 추출, CNN128 모델 3개의 학습을 진행합니다. 실제 원본 수 × 증강 횟수를 검사합니다.
6. 학습과 분리된 합성 호출어·배경음으로 평가하고 결과 화면을 제공합니다. 순위·성공률·오호출·실제 채점 WAV를 확인하거나 마이크로 시험합니다. 마이크 음성은 저장하거나 학습하지 않습니다.

**성능 평가용 배경 음원**은 한국어 자유발화·대화10시간, 다른 화자의 인터뷰5시간, 한국어 낭독3시간, 다른 언어4시간, 음악3시간, 환경음4시간, 전자음1시간의 **총30시간**을 기준으로 준비합니다. 기존193개 짧은 배경은 보조 자료로 유지합니다. 자료마다 실제 준비량·출처·조건을 표시하며, 인터뷰를 TV방송으로 표시하거나 미확보 음악을 한국어 보컬로 간주하지 않습니다. Seoul의 비상업 조건 등 원출처 조건도 확인하세요.

**평가 기준은 학습 규모와 별개로 동일합니다.** 공통 평가 v2는30음색·호출 원본5,000개의 일반 소음 시험80,000회에, 대표625개 원본의 일반·강한 잔향 시험20,000회를 더해 **총100,000회**를 시험합니다. 학습과 분리한 가상 공간20개·RIR80개를 사용하고 잔향별 결과도 구분합니다. 학습 음성1,000개를 선택해도 평가 기준은 줄이지 않습니다. 배경 다운로드와 완성된 평가 WAV는 검증 후 재사용합니다.

자료·표본·오호출 시험 시간이 부족하면 결과 화면에 이유를 표시합니다. 30시간은 다운로드·검수·채점이 모두 완료된 분량이 아니라 준비 기준입니다. 짧은 배경을 반복해 공통30시간·최종100시간을 채우지 않습니다. 공통 평가는 모델 비교용이며, 독립 최종 평가는 모델·설정 동결 후 별도 자료로 진행합니다. [최종 평가 절차](LIBRARY_GUIDE.md#8-모델설정-확정-후-최종-평가하기)를 따르세요.

호출어 한 원본에서는 같은 배경 원본·구간으로 SNR 20·15·10·5·0 dB를 비교합니다. 같은 원본을 여러 세기로 사용해도 원본 수를 늘려 세지 않습니다. 실제 사용한 종류·원본·조건별 표본 수와 시험하지 못한 후보를 기록합니다. 자세한 구성과 분리 검증 범위는 [평가 자료 안내](DATASETS.md#성능-평가용-배경-음원)를 참고하세요.

검수가 필요한 동안 관련 생성·학습은 시작하지 않습니다. 검수 결과를 저장하면 서버가 근거를 확인하고 다음 단계로 넘어갑니다. 문제가 있어 보류된 항목은 정상으로 바꾸어 처리하지 않습니다. 변경이 필요한 경우 자료나 생성 방식의 예외를 해결해야 합니다.

## 중단하고 이어서 하기

**현재 단계 후 일시정지**는 파일을 쓰는 작업을 강제로 죽이지 않습니다. 현재 단계를 마친 뒤 멈춥니다. 서버 창을 갑자기 닫아도 이미 실행 중인 한 단계는 계속 돌아갈 수 있습니다. 다시 열면 실제 PID와 생성 시각, 완료 기록을 확인해 중복 실행을 막습니다.

컴퓨터가 꺼져 작업이 중단됐다면 같은 작업 폴더에서 `koww web`을 실행하고 **이어서 진행**을 누르세요. 다운로드는 부분 파일을, 생성은 검증한 완료 발화를, 특징·학습·평가는 해시가 맞는 재개 기록을 사용합니다. 평가는32세션마다 점수를 저장하므로 중단 직전 일부는 다시 계산할 수 있습니다. 다른 살아 있는 작업의 잠금은 해제하지 않으며, 코드·설정·입력이 달라진 실험을 같은 작업으로 이어붙이지 않습니다.

진행률은 해당 작업에서 확인한 실제 수량입니다. 완료 단계 수를 전체 작업 시간의 비율로 표시하지 않습니다. 남은 시간은 현재 단계에서 실제 처리 속도를 측정할 수 있을 때만 표시하며, 검수 대기와 아직 측정하지 않은 다음 단계까지 포함한 전체 완료 시간은 아닙니다.

## 라이브러리 업데이트

웹 서버를 실행한 창에서 Ctrl+C로 종료한 뒤 저장소 폴더에서 실행합니다. 작업이 진행 중이면 먼저 **현재 단계 후 일시정지**를 누르고 해당 단계가 끝날 때까지 기다리세요.

```powershell
git pull --ff-only
. .\scripts\Use-ProjectStorage.ps1
.\.venv\Scripts\python.exe -m pip install --no-deps .
.\.venv\Scripts\python.exe -m korean_openwakeword web
```

기존 자료·모델·평가 결과는 삭제하지 않습니다. 한 단계도 실행하지 않은 웹 프로젝트는 설정과 실행 기록을 확인한 뒤 새 코드로 연결합니다. 이미 실행한 실험의 코드 결합은 자동 해제하지 않으며, 확대된 평가 구성을 적용하려면 새 실험을 만드세요. 과거 평가 결과를 새 결과로 덮어쓰지 않습니다. 위 명령은 라이브러리만 업데이트하며 기존 PyTorch 설치를 변경하지 않습니다.

## 큰 규모와 성능 확인 범위

기본 공개 Generic 특징은 약 2,000시간이고, 한국어 자동 준비는 동작 확인용 1시간부터 시작합니다. 선택한 목표가 더 크면 부족분을 표시합니다. 화면에서 추가 음원 폴더·자료 형식·용도·시간을 지정하면 전처리와 대표 검수를 이어서 진행합니다. 기존 승인 기록을 연결하는 방법도 제공합니다. 제공자 메타데이터나 출처·이용 조건이 필요한 자료는 상세 항목을 입력해야 하며, 임의로 한국어·화자·소음 범주를 추정해 승인하지 않습니다.

같은 파일을 복제하거나 2,000시간을 7,500시간으로 기록하지 않습니다. 충분한 Generic 원본을 추가하면 기존 숫자 파일을 보존하고 원본 전체로 별도의 특징 배열을 만듭니다. 두 자료의 겹침을 확인할 수 없으므로 단순히 시간을 합산하지 않습니다. 기존 `KOWW_CACHE_ROOT`를 명시한 경우 그 캐시를 보존해 재사용하며 실제 저장 위치를 프로젝트에 기록합니다.

세 규모 모두 같은 평가 호출어와 비호출 음원으로 공통 평가를 진행합니다. 채점은 입력 순서와 CPU 계산을 유지하면서 오디오 세션 단위로 최대4개 작업자를 사용하고, 여유 RAM·CPU와 작업 수에 따라 수를 줄입니다. 점수는 디스크에 저장해 불필요한 RAM 중복을 줄입니다. 전체 시간은 해당 컴퓨터에서 실제 처리 속도를 측정해 표시하며 GPU가 항상 빠르다고 가정하지 않습니다.

공통 평가 결과만으로 독립 최종 평가나 다수 실제 화자의 성능을 검증했다고 판단하지 않습니다. 웹 흐름은 Final을 자동 해제하지 않습니다. 기준은 [학습 계획](../plan.md)과 [평가 가이드](LIBRARY_GUIDE.md#8-모델설정-확정-후-최종-평가하기)를 따릅니다.
