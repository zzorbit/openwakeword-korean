# 학습 데이터 다운로드와 재사용

**호출어 음성은 Qwen TTS로 새로 생성**합니다. 비호출·소음·잔향 자료는 공개 데이터셋에서 내려받아 여러 호출어 학습에 재사용할 수 있습니다.

이 문서는 자료를 구하는 방법을 안내합니다. 압축을 푼 음원은 [공개 음원 자동 준비](DATA_FORMAT.md#공개-음원-자동-준비)의 명령으로 변환·분리·검수·연결합니다. 전체 순서는 [학습 가이드](LIBRARY_GUIDE.md)를 참고하세요.

`koww init`에서 자료 목표 시간을 선택합니다. 기본 상용 모델용 비호출은 **일반 7,500시간·한국어 2,500시간(75:25)**이며 설정 요약에 기록됩니다. 동작 확인용은 일반 **2,000시간·한국어 1시간**, 시험 모델용은 [README](../README.md#학습-규모-선택)의 값을 직접 입력하세요. 환경소음 시간은 별도 준비 목표로 선택할 수 있지만 학습 배치에 추가하지 않습니다. 목표 시간만 바꿔서는 실제 자료가 늘거나 줄지 않습니다.

공개 Generic 사전 계산 파일은 약 2,000시간입니다. 상용 모델용의 7,500시간을 채우려면 더 큰 원본 자료를 확보해 같은 frontend로 특징을 만들고 연결해야 합니다. 원본·구간을 중복 집계하거나 공개 파일을 복제해 시간을 늘리지 않습니다. 유사어는 [별도 자료 목록](DATA_FORMAT.md#유사어-학습-자료)으로 연결하며, 배치마다 100개를 뽑습니다.

**시작값은 데이터량을 최적화해 확정한 값이 아닙니다.** 새 호출어를 준비할 때 공식 학습 안내·공식 모델 설명서·공개 학습 사례를 먼저 확인하고, 권장 규모와 실제 사용 사례를 구분해 자료량을 정합니다. 확인한 출처와 선택 이유는 프로젝트 계획에 남기며, [데이터량 선정 기준](../plan.md#데이터량의-근거와-선택-원칙)을 따릅니다.

## 어떤 자료를 받나요?

| 용도 | 공개 자료 | 참고할 점 |
| --- | --- | --- |
| 일반 비호출 특징(Generic) | [openWakeWord features](https://huggingface.co/datasets/davidscripka/openwakeword_features) | 제공자가 미리 계산한 숫자 배열. 명목 약 2,000시간이며 원본 WAV와 행별 출처는 없음 |
| 한국어 비호출 음성 | [YODAS 한국어](https://huggingface.co/datasets/espnet/yodas), [Zeroth Korean](https://www.openslr.org/40/) | 대화·음성 콘텐츠를 확보해 한국어 간섭 조건에 사용 |
| 환경음·음악 | [DNS-Challenge](https://github.com/microsoft/DNS-Challenge), [MUSAN](https://www.openslr.org/17/) | 종류가 다양한 자료를 선택. 음악과 환경소음 시간은 따로 기록 |
| 잔향(RIR) | [RIRS_NOISES](https://www.openslr.org/28/) | 공간의 울림을 재현. 잔향 파일 길이를 환경소음 시간으로 계산하지 않음 |
| 별도 평가용 한국어 음성 | [Seoul Corpus](https://www.openslr.org/113/) | 학습 원본과 분리해 평가 배경·연속 비호출에 사용 |

공개되어 있어도 자료마다 이용조건이 다릅니다. 출처와 제공자의 라이선스·원문 안내를 보존하세요. 코드의 Apache-2.0 라이선스를 음원 전체에 적용하지 않습니다. Generic은 제공자 CC BY-NC-SA 4.0, YODAS는 CC BY 3.0, Zeroth는 CC BY 4.0, Seoul은 CC BY-NC 2.0으로 기록되어 있습니다. MUSAN·DNS·RIRS는 개별 원출처 조건도 확인합니다. 자세한 조건은 [이용조건·출처](../THIRD_PARTY_NOTICES.md)에 있습니다.

## 공식 자동 학습 예제의 증강 재료

README의 **동작 확인용·시험 모델용**은 모두 [openWakeWord 공식 자동 학습 예제](https://github.com/dscripka/openWakeWord/blob/main/notebooks/automatic_model_training.ipynb)와 같은 증강 재료를 준비합니다. 두 단계의 AudioSet 일부·음악 1시간·MIT RIR은 아래의 동일한 자료와 준비 범위를 뜻합니다.

| 재료 | 공식 예제의 준비 범위 | 사용하는 이유 |
| --- | --- | --- |
| AudioSet | [agkphysics/AudioSet의 압축파일 보존 버전](https://huggingface.co/datasets/agkphysics/AudioSet/tree/5a2fa42a1506470d275a47ff8e1fdac5b364e6ef)의 `data/bal_train09.tar` 압축파일 1개 | 말소리·음악·생활 소리 등 실제 배경음을 호출어에 섞음 |
| FMA 음악 | [rudraml/fma](https://huggingface.co/datasets/rudraml/fma)의 `small` 구성에서 30초 음원 120개, 총 1시간 | 음악이 들리는 상황을 학습 |
| MIT 잔향(RIR) | [MIT_environmental_impulse_responses](https://huggingface.co/datasets/davidscripka/MIT_environmental_impulse_responses)의 `train` 전체 | 실제 공간에서 측정한 울림을 호출 음성에 적용 |

**AudioSet 일부**는 임의의 시간 목표가 아니라 위 압축파일 하나를 뜻합니다. 공식 예제는 이 파일의 총 오디오 시간을 따로 명시하지 않으므로, 압축을 푼 뒤 실제 시간을 기록합니다. AudioSet은 [Google이 공개한 다양한 실제 소리 자료](https://research.google.com/audioset/)입니다.

AudioSet의 최신 버전은 Parquet 형식으로 바뀌어 기존 압축파일 경로가 없습니다. 공식 예제와 같은 파일을 받을 때는 위의 고정 버전 `5a2fa42a1506470d275a47ff8e1fdac5b364e6ef`를 사용하세요. [직접 다운로드](https://huggingface.co/datasets/agkphysics/AudioSet/resolve/5a2fa42a1506470d275a47ff8e1fdac5b364e6ef/data/bal_train09.tar)의 크기는 **968,540,160바이트**이며 SHA256은 `9ab88550e77c8289acf71d19ae3f254fadad16f3cea305ef08a16949a928acf9`입니다. 내려받은 파일의 크기·해시를 확인한 뒤 압축을 풉니다.

**MIT RIR**은 소음 녹음이 아니라 소리가 공간을 거치면서 어떻게 울리는지 측정한 자료입니다. 음성에 적용하면 해당 공간의 울림을 재현할 수 있습니다. [MIT 원출처](https://mcdermottlab.mit.edu/Reverb/IR_Survey.html)와 Hugging Face의 실제 파일 목록을 함께 기록하며, 파일 개수는 내려받은 버전에서 확인합니다.

잔향 재료는 **상용 모델용도 동일한 MIT RIR의 `train` 전체**로 준비합니다. 호출어 원본이 많아져도 같은 공간의 RIR을 여러 호출 음성에 적용할 수 있으므로 자료 수를 비례해서 늘릴 필요는 없습니다. 개발용 평가에서 부족한 공간 조건이 확인되면 다른 공개 RIR을 추가하며, 평가용 RIR의 분리는 유지합니다.

일반 비호출 2,000시간은 위 증강 재료와 별도로 [openWakeWord 사전 계산 특징](https://huggingface.co/datasets/davidscripka/openwakeword_features)의 `openwakeword_features_ACAV100M_2000_hrs_16bit.npy`를 사용합니다. 이 파일에는 원본 음성이 없어 소음 혼합 재료로 사용할 수 없습니다.

공식의 호출어 **최소 20,000개 권장**은 [학습 설정](https://github.com/dscripka/openWakeWord/blob/main/examples/custom_model.yml)의 원본 수 안내이며, 20,000개 전용 증강 재료나 필수 시간을 따로 지정하지 않습니다. 자동 학습 예제는 위 자료를 사용하고, 본격 학습에는 전체 AudioSet과 추가 배경 자료(FSD50K·Freesound 등), 더 많은 FMA 음악을 권장합니다. 한국어 호출어의 시험 모델용에는 한국어 비호출 원본 음성도 배경으로 재사용할 수 있습니다.

공식 예제의 자료 수집·16kHz WAV 변환 코드를 참고해 위 원본 음원을 준비한 뒤 [자료 목록 작성법](DATA_FORMAT.md)으로 연결합니다. 아래 기본 다운로드 명령의 MUSAN·RIRS_NOISES는 대체하거나 추가할 수 있는 자료이며, FMA·MIT 자료와 서로 다른 데이터셋입니다. `koww download-data --dataset rir`는 RIRS_NOISES를 받으므로 MIT 자료를 받는 명령으로 사용하지 않습니다.

## 기본 자료 다운로드

### 상용 모델용의 소음 증강 재료

상용 모델용은 **학습용 일반·한국어 비호출 원본 오디오를 재사용**합니다. 별도 AudioSet·FMA 증강 묶음을 추가로 받지 않고, 검수·승인한 비호출 원본을 소음 증강 목록에도 연결합니다. 같은 파일을 복사하거나 고유 시간을 중복 합산하지 않습니다.

환경음·음악·한국어와 다른 언어의 말소리를 포함하도록 비호출 자료를 구성합니다. 사전 계산된 특징만 있는 자료는 오디오 혼합에 사용할 수 없으며, 평가용으로 분리한 원본도 포함하지 않습니다. 선택한 비호출 분량이나 필요한 소음 종류가 부족하면 실제 부족분을 표시하고 추가 자료를 연결한 뒤 진행합니다.

### 직접 다운로드하기

저장소 폴더에서 명령을 실행합니다. `shared/`는 여러 호출어에서 공유할 자료를 두는 예시이며, 원하는 데이터 폴더로 바꿀 수 있습니다. SSD나 HDD 중 특정 장치를 사용할 필요는 없습니다.

```powershell
koww datasets
koww download-generic --output shared/openwakeword_features_ACAV100M_2000_hrs_16bit.npy
koww download-data --dataset zeroth --output shared/zeroth_korean.tar.gz
koww download-data --dataset musan --output shared/musan.tar.gz
koww download-data --dataset rir --output shared/rirs_noises.zip
```

`koww datasets`는 자료의 출처·버전·파일 크기·이용조건을 보여줍니다. 기본 다운로드 파일의 크기는 다음과 같습니다. 압축 해제한 음원과 학습 결과의 용량은 별도입니다.

| 파일 | 다운로드 크기 |
| --- | --- |
| Generic 특징 | 약 17.28GB |
| Zeroth | 약 10.34GB |
| MUSAN | 약 11.09GB |
| RIRS_NOISES | 약 1.31GB |

GB는 10억 바이트 기준입니다. 중단된 다운로드는 같은 명령으로 이어받습니다. 완료 시 크기와 SHA256을 확인하고 다운로드 기록을 남기며, 정확한 파일이 이미 있으면 다시 받지 않습니다.

## 한국어 음성 추가 확보: YODAS

새 프로젝트의 한국어 비호출 목표는 동작 확인용 **1시간**, 시험 모델용 약 667시간, 상용 모델용 2,500시간입니다. 시험 모델용·상용 모델용은 Zeroth만으로 채울 수 없으므로 YODAS와 다른 공개 한국어 자료를 조합하고, 실제 확보한 고유 시간과 출처를 기록합니다. 아래 고정 다운로드 목록은 초기 표본 모델에서 사용한 범위이며 새 목표 시간 전체를 제공하는 목록은 아닙니다.

라이브러리에는 초기 표본 모델에서 확보한 **ko000 압축 파일 30개의 고정 버전·해시·크기**가 기록되어 있습니다. 목록은 `koww datasets`, 원본 기록은 [public_datasets.json](../korean_openwakeword/resources/public_datasets.json)에서 확인합니다.

파일 한 개를 받는 예시입니다.

```powershell
koww download-data --dataset yodas_00000002 --output shared/yodas/ko000_00000002.tar.gz
```

필요한 파일부터 받고, 실제 사용 가능한 고유 시간을 합산하세요. 30개를 모두 내려받으려면 아래 코드를 `download_yodas.py`로 저장한 뒤 실행합니다. 전체 목록을 받는 대용량 작업입니다.

```python
from pathlib import Path
from korean_openwakeword.downloads import dataset_catalog, download_dataset

for key, asset in dataset_catalog()["assets"].items():
    if key.startswith("yodas_"):
        download_dataset(key, Path("shared/yodas") / asset["filename"])
```

제공자의 압축 음원을 사용하며 YouTube 영상을 따로 수집하지 않습니다. 같은 영상의 발화를 학습·평가 양쪽에 나누지 않고, 영상 ID를 화자 ID라고 기록하지 않습니다. 제공된 전사는 재사용할 수 있지만 모든 음원을 별도로 STT하는 과정은 기본 절차가 아닙니다.

## 다양한 환경소음 확보: DNS

팬·에어컨·청소기·도로·차량·비·바람·키보드·문·그릇·충격음·생활 기계음 등 **소음 종류의 다양성**을 먼저 확보하세요. 상용 모델용은 학습용 비호출 원본 안에서 이런 소리를 선택합니다. DNS는 부족한 종류를 추가하고 싶을 때 선택할 수 있는 자료이며 별도 필수 다운로드가 아닙니다.

[고정 버전의 소음 폴더](https://github.com/microsoft/DNS-Challenge/tree/70f19285c36cca4df2338f9248775ddc50980c6b/datasets/noise)에서 필요한 자료를 선택합니다. 같은 종류의 긴 녹음만 추가해 시간을 채우지 않습니다. 원출처·원본 ID·이용조건도 보존하세요.

음성이 포함된 간섭은 한국어 자료를 우선 사용합니다. 일반 환경음에는 언어 기준을 적용하지 않습니다.

## 성능 평가용 배경 음원

호출어에 배경을 섞어 **소음 속 감지율**을, 배경만 재생해 **오호출**을 확인하는 자료입니다. 새 웹 프로젝트의 세 학습 규모는 **같은 공통 평가 v4**를 사용합니다. 호출 원본5,000개·합성 음색30계열, 비호출 원본30시간과 별도 잔향 자료를 준비하며, 평가용 파일을 학습에 넣지 않습니다. 기존 v1/v2/v3 프로젝트의 설정과 완료 결과는 유지합니다.

| 종류 | 준비량 | 공개 자료와 선택 기준 |
| --- | ---: | --- |
| 한국어 자연 대화·자유발화 | 10시간 | [Seoul Corpus, OpenSLR113](https://www.openslr.org/113/). 자유주제 인터뷰 대화의30화자에서 각20분을 목표로 선택 |
| 한국어 인터뷰 음성 | 5시간 | 같은 자료의 다른10화자에서 각30분. TV·방송·강연 자료를 확보한 것으로 표시하지 않음 |
| 한국어 낭독 | 3시간 | [Zeroth, OpenSLR40](https://www.openslr.org/40/)에서 학습 화자와 분리해 공통 평가 목록에 고정한 자료 |
| 다른 언어의 말소리 | 4시간 | [MUSAN, OpenSLR17](https://www.openslr.org/17/)의 LibriVox. 제공된 언어 정보에 따라 배분하며 미상 화자 신원은 추정하지 않음 |
| 음악·보컬 | 3시간 | MUSAN의100곡·여러 음악가·장르를 목표로 선택. 변형을 허용하는 원본 조건 확인 |
| 환경·생활음 | 4시간 | [FSD50K 공식 자료](https://zenodo.org/records/4060432)의 평가 묶음에서 제공자 소리 분류로 선택 |
| 전자음·알람·경보 | 1시간 | 같은 FSD50K 묶음의 기기·벨·경보 등. 환경음과 중복 시간을 합산하지 않음 |

위30시간은 **준비할 기준량이며, 라이브러리 설치만으로 내려받거나 검수한 분량이 아닙니다.** 웹에서 [고정 준비 목록](../korean_openwakeword/resources/evaluation_materials_v1.json)의 원본 묶음을 다운로드·검증·변환한 뒤 실제 시간·화자·곡·종류·부족분을 기록합니다. 한국어 보컬 비중을 확보했다고 주장하지 않으며, 청취 판단이나 출처 확인이 필요한 자료는 승인 전 연결하지 않습니다. 자료 원본·구간을 고정해 모든 후보 모델에 같은 시험 오디오를 사용합니다.

**새 공통 평가에는 위 일곱 범주만 사용합니다.** 같은 원본을 호출어 혼합과 연속 비호출 시험에 재사용하며, 기존193개 보조 배경과 별도 한국어 낭독 예약분은 추가하지 않습니다. 표의 한국어 낭독3시간은 새 고정 목록 안의 자료이며, 과거 예약분을 별도로 더하는 항목이 아닙니다.

**이용조건은 코드와 별개입니다.** Seoul Corpus는 CC BY-NC2.0으로 비상업 조건이 있습니다. Zeroth는 CC BY4.0, LibriVox는 제공된 Public Domain 조건을 따르며, MUSAN 음악은 각 원본의 CC BY/SA 등 조건을 보존합니다. FSD50K는 선택한 원본의 CC0/CC BY를 확인합니다. 변형 금지·미확인 조건의 음원은 자동 채택하지 않습니다. 학습 규모의 ‘상용 모델용’이라는 이름이 평가 음원의 상업적 이용 허가를 뜻하지 않습니다.

### 잔향과 호출 시험 수량

잔향은 [OpenSLR28 RIRS_NOISES](https://www.openslr.org/28/)의 **서로 다른 가상 공간20개·RIR80개**를 사용합니다. 가상 방에서 계산한 응답이며 실제 방에서 측정한 MIT 학습 자료와 구분합니다. T20 방식으로 추정한 잔향 시간(RT60)을 기준으로 일반 실내0.2–0.6초·강한 울림0.6–1.8초로 나눕니다. RIR 개수·방 개수를 비호출 음원 시간에 더하지 않습니다.

| 호출 시험 | 계산 | 수량 |
| --- | --- | ---: |
| 잔향 추가 없음 | 원본5,000개 × 16조건(Clean1 + 소음15) | 80,000회 |
| 일반 실내 잔향 | 고정 대표 원본1,000개 × 같은16조건 | 16,000회 |
| 강한 실내 잔향 | 같은 대표1,000개 × 같은16조건 | 16,000회 |
| **합계** | 평가 음색·스타일을 고르게 배분 | **112,000회** |

대표 원본1,000개는 음색·말투·속도·억양·발성·호출 길이 분포를 고르게 고정 seed로 추출합니다. 두 잔향 강도에 같은 원본을 사용하고, 잔향 없는 대응 조건은 기본80,000회 안에서 비교하므로 중복 생성하지 않습니다. 이 수량은 시험 비용과 다양성을 고려한 선택이며 최적량이 입증된 값은 아닙니다.

같은 호출의 같은 배경 원본·구간을 SNR20·15·10·5·0dB에서 비교하며, 잔향 적용 후 SNR을 맞춥니다. 30시간의 비호출 시험은 위 호출 수량과 별개입니다. 모든 후보 모델은 완성된 동일 WAV 전체로 채점하며 시험할 때마다 다른 일부를 무작위로 뽑지 않습니다.

### 과거 결과 재현용 자료

다음 내용은 **과거 v1/v2/v3 결과를 재현할 때만** 적용합니다. 이전193개·약109.2MB·38.9분 목록과 별도 Zeroth 낭독 예약분, 기존 설정·검수·평가 파일은 보존합니다. 새 공통 평가 v4에서는 이 자료를 다운로드·검수·추가 연결하거나 시험 시간에 합산하지 않습니다.

| 종류 | 구성 | 파일 수 |
| --- | --- | ---: |
| 환경·생활음 | 날씨·가전·차량·충격음·동물·기침·웃음·물소리 등30종 | 종류별5원본, 총150개 |
| 전자음·경보음 | 알람·시계음·경적·사이렌·종소리 | 종류별5원본, 총25개 |
| 실제 음악 | 피아노·기타·드럼·보컬과 재즈·테크노·힙합·록·관현악·하우스 등 | 서로 다른12원본 |
| 한국어 현장 대화·안내방송 | 시장·식당·거리·지하철의 한국어 대화와 지하철 안내방송 | 서로 다른 원본 6개 |

환경음·전자음은 [고정 버전의 ESC-50](https://github.com/karolpiczak/ESC-50/tree/33c8ce9eb2cf0b1c2f8bcf322eb349b6be34dbb6), 음악은 Freesound의 [피아노·드럼](https://freesound.org/people/mlivick/sounds/577351/), [기타·드럼](https://freesound.org/people/Nadia4Sound/sounds/476018/), [보컬 멜로디](https://freesound.org/people/buggly/sounds/505438/), [보컬 패드](https://freesound.org/people/deadrobotmusic/sounds/574337/)입니다. 음악은 공개 HQ MP3 미리듣기 파일을 사용하며, 로그인 후 받는 원본 WAV와 구분합니다. 음원의 언어나 화자 신원은 추정해서 기록하지 않습니다.

한국어 현장 음원은 Freesound의 [시장](https://freesound.org/s/855252/), [식당](https://freesound.org/s/165123/), [지하철 대화](https://freesound.org/s/155215/), [먹거리 거리](https://freesound.org/s/157474/), [서울 거리](https://freesound.org/s/345026/), [지하철 대화·안내방송](https://freesound.org/s/29650/)입니다. 게시자의 설명을 근거로 한국어 현장 녹음으로 분류했으며 환경음도 함께 들어 있습니다. 긴 현장 녹음은 중앙 15초를 대표 청취하고, 전체 원본 사용에 동의한 자료만 평가에 연결합니다. 대표 청취를 전체 원본의 개별 청취 완료로 기록하지 않습니다. 이 자료를 TV·라디오 방송, 한국어 노래나 신원이 확인된 개별 화자로 표기하지 않습니다.

**이용조건은 자료마다 다릅니다.** ESC-50은 CC-BY-NC-3.0, ESC-10 하위 자료는 CC-BY-3.0이며 원본 Freesound별 조건도 보존합니다. 음악과 한국어 현장 음원은 개별 원출처의 Creative Commons 조건을 따릅니다. 웹에서 개별 출처·조건을 확인하세요. 음원은 설치 패키지에 넣지 않고, [고정 목록](../korean_openwakeword/resources/evaluation_backgrounds_v4.json)의 URL·크기·SHA256으로 다운로드를 검증합니다. 각 해시는 실제 내려받은 공개 파일의 고정 값이며, 제공자가 별도로 발표한 체크섬이라고 주장하지 않습니다.

### 공통 자료의 검수와 실제 평가 시간

평가 음원은 검수 화면에서 대표 구간과 묶음 이용 조건을 확인한 뒤 승인한 자료만 **Development 평가**에 연결합니다. 이전 판단은 원본·음원·답변·승인 기록의 해시가 모두 맞을 때만 재사용하며 폐기한 자료를 자동 복원하지 않습니다. 학습 자료나 잠긴 Final 자료로 승인하지 않습니다. 평가 목록의 원본 ID·파일 해시와 알려진 학습 음원을 대조하고, 길이가 같은 원본은 정규화 PCM 해시도 비교해 캐시합니다. 모든 비호출 음원을 다시 디코딩하거나 STT하지 않습니다. 원본 대응표가 없는 공개 Generic 특징 전체와의 중복, 모든 편집본·유사 음원, 미확인 화자까지 완전히 분리했다는 검사는 아닙니다.

원본은 보존하고 평가 WAV는 16kHz 모노 PCM16으로 변환합니다. 원본 디코딩 결과의 과도한 포화는 거부하며, resampling 과정에서만 최대 진폭이 1을 넘으면 전체 음량을 선형 감쇠하고 적용 배율·진폭을 기록합니다. 듣기와 채점에는 같은 변환 WAV를 사용합니다. 기존 학습 자료·승인 기록은 다시 만들지 않고 새 평가 준비·승인 기록을 버전별로 남깁니다.

공통 평가의 실제 충족 여부는 결과의 `common_coverage_*.json`에 따로 기록합니다. 다운로드된 길이·검수 승인한 고유 길이·실제 채점한 유효 시간을 구분하며, 작은 자료의 반복이나 여러 모델의 시간을 합쳐30시간으로 계산하지 않습니다.

오호출 시험에서는 짧은 원본마다 처리기를 초기화하는 손실을 줄이기 위해, 승인한 서로 다른 원본을 종류별 약10분의 연속 WAV로 묶습니다. 초기화로 제외되는 시간은 같은 자료 목록의 미사용 원음으로 필요한 만큼 보충하고, 기본30시간·보충량·실제 채점 가능한 시간을 따로 기록합니다. 소음 혼합에는 기본 목록의 개별 원본만 사용하며 보충 원음을 추가하지 않습니다. 연결 파일에는 무음·효과·반복을 추가하지 않으며 원본별 해시·구간·출처를 보존합니다. 원본 시간은 한 번만 집계합니다.

## 독립 최종 평가 자료

학습·공통 평가에 쓰지 않은 원본·배경·잔향·합성 음색을 별도로 준비합니다. 다른 데이터셋의 이름이 붙어 있어도 같은 녹음의 편집본·복사본이면 사용할 수 없습니다. 알려진 화자·음악가·방 정보와 원본·파일·PCM 해시, 혼합 오디오의 구성 자료를 검사합니다. 출처를 확인할 수 없는 배경은 Final에 연결하지 않습니다.

공통 평가용 파일을 `split: final`로 바꾸거나 같은 원본의 다른 구간을 가져오는 방식은 허용하지 않습니다. 원본 대응표가 없는 Generic 특징, 신원을 확인하지 못한 현장 화자, 모든 임의 편집본·음향적 유사 음원의 완전한 독립성까지 자동 증명하지는 않습니다. 검사 결과에 한계를 남깁니다. 자료 연결과 동결 후 검사는 [최종 평가 절차](LIBRARY_GUIDE.md#8-모델설정-확정-후-최종-평가하기)를 따르세요.

## 다운로드 후 해야 할 일

1. 압축을 풀고 원출처·이용조건을 보존합니다. 압축 도구는 대상 폴더 밖으로 파일이 나가지 않게 사용합니다.
2. 원본 녹음·영상·화자·방 단위로 학습/개발/최종 평가 자료를 분리합니다. 같은 원본의 절단본이나 복사본도 같은 원본으로 관리합니다.
3. 파일 품질과 대표 구간의 내용을 확인합니다. 새 호출어가 실제로 포함된 비호출 구간은 제외합니다.
4. [자료 목록](DATA_FORMAT.md)에 파일 경로·해시·출처·분할·검수 결과를 기록합니다.
5. [학습 가이드](LIBRARY_GUIDE.md#5-비호출소음잔향-자료-연결하기)의 `audit`·`windows`·`import-generic` 순서로 프로젝트에 연결합니다.

같은 소리가 여러 파일·증강 결과에 반복되어도 고유 원본 시간은 늘어나지 않습니다. 음악을 한국어 대화 시간으로, 잔향을 환경소음 시간으로 계산하지 않습니다. 확보하지 않은 방송·보컬 범주를 확보한 것처럼 기록하지 않습니다.
