# 웹 학습 흐름과 코드 정리

2026-11-11 기준. 새 호출어는 모두 같은 챕터 화면과 검수 흐름을 사용합니다. 호출어 이름이나 기존 모델 번호에 따라 화면을 바꾸지 않습니다.

## 기본 화면과 검수

- 기준 목소리 생성 → 기준 목소리 검수 → 호출어 샘플 생성 → 호출어 발음 사전 검수 → 호출어 음성 생성 → 호출어 발음 검수 → 유사어 입력·생성·검수 → 증강·특징 추출 → 학습 → 평가 → 결과 순서로 진행합니다.
- 기준 목소리 후보는 성별 2종과 연령 5종의 분류별로 준비합니다. 후보 5개씩 비교하고, 목표 수량 안에서 자유롭게 선택하며 추가 후보와 이전 후보를 오갈 수 있습니다. 후보 옵션·시드와 재생 상태를 표시합니다.
- 검수 화면은 목록·재생 바·부적합 판정의 공통 배치를 사용합니다. 목록 밖을 누르면 닫히며, 저장과 다음 단계의 준비가 완료된 뒤 화면을 전환합니다.
- 생성·학습·평가·결과 정리는 같은 진행 행을 사용합니다. 전체 수량이 아직 없을 때는 준비 상태와 대기 게이지를 표시하며 진행률을 만들어내지 않습니다.
- 학습 자료 검증, 장치 확인, 모델 초기화, GPU 캐시 적재를 실제 학습 업데이트와 구분합니다. GPU 적재량은 실제 복사한 바이트를 표시하고, 진행 파일 기록은 초당 한 번 수준으로 제한합니다.

## 오류와 비효율 개선

동작 확인용 학습에서 발견한 진행 표시와 화면 전환 문제를 0.33.1과 0.33.2에 반영했습니다. 0.33.2에서는 처음 열린 화면에 현재 호출어의 상세 정보만 읽습니다. 다른 호출어는 전환할 때, 자료 계획과 규모는 해당 화면을 열 때 확인합니다.

음성 생성과 학습의 남은 시간은 작업자가 최근에 처리한 수량과 소요 시간으로 추정합니다. 모델 적재, GPU 가속 확인, 자료 검증은 별도 상태로 표시합니다. 호출어·유사어 발음 검수는 목록과 재생기를 준비한 뒤 열립니다.

- 다운로드 행은 전송량과 무결성 검증률을 구분합니다. 환경 준비·추출 검증·자료 연결 중에도 현재 작업 안내를 유지합니다.
- 초기 후보 준비는 최종 선택 목소리 수가 아닌 실제 생성할 후보 수를 공통 진행률과 예상 시간에 사용합니다.
- 모델 적재·복제 정보 준비·화자별 가속 검사는 예상 시간의 처리 속도 표본에서 제외합니다. 작업·단계·실제 증분이 안정된 경우에만 예상 시간을 표시합니다.
- 유사어 저장과 마지막 분류 승인은 첫 다음 클릭의 의도를 유지합니다. 저장 성공과 완료 근거를 확인하고 예상한 단계 경계만 한 번 해제합니다. 실패·취소·프로젝트 전환 뒤의 늦은 응답은 다음 작업을 시작하지 않습니다.
- 평가자료 생성 수량과 긴 음원의 실제 계산 활동을 현재 작업에 묶어 보고합니다. 마지막 음원이 만들어지거나 계산 프레임이 증가해도 최종 검증과 완료 기록을 대신하지 않습니다.

| 문제 | 처리 |
| --- | --- |
| 이전 목록·재생 바가 카드 검수 전에 잠깐 노출됨 | 카드 검수와 목록형 재생 화면을 분리하고, 필요한 UI만 생성합니다. |
| 다음 단계 이동 안내가 끝난 뒤 내용이 늦게 표시됨 | 화면과 하위 프레임의 준비 완료를 확인한 뒤 전환합니다. 실제 장시간 작업은 해당 챕터에서 표시합니다. |
| 선택·해제와 목록 여닫기에서 위치가 흔들림 | 재생 UI와 선택 상태를 분리하고, 고정된 진행 행 안에서 내용만 갱신합니다. |
| 음성 옵션 JSON 추가를 학습 자료 변경으로 오인함 | 자료 검증 대상 JSON을 명시적으로 등록합니다. 기존 자료 증명에 묶인 해시와 계보 검사는 유지합니다. |
| 무음이 긴 기준 음성에서 호출어 생성이 반복 실패함 | 원본을 보존한 입력 정리와 제한된 재시도로 실패한 항목만 복구합니다. |
| 부적합 음원 때문에 전체 본 생성이 막힘 | 해당 목소리의 호출어만 새로 만들고 재검수합니다. 이미 적합한 음원·판정은 보존합니다. |
| 학습 준비 중 계속 0회로만 보임 | 실제 준비 단계와 GPU 적재량을 별도로 보고합니다. 모델·배치·난수·학습 계산은 바꾸지 않습니다. |
| 결과 페이지 준비 때 평가 WAV를 모두 복사함 | 로컬 결과는 기존 채점 WAV를 참조하고, 재생 요청한 파일만 해시 검증합니다. 독립형 내보내기는 복사 방식을 유지합니다. |
| 긴 배경음 평가 중 진행 수량이 오래 고정됨 | 현재 작업의 실제 프로세스가 소유한 저장 체크포인트를 읽어 로그 사이의 완료 수량도 표시합니다. |
| 같은 실행 계약을 만들 때마다 AST 전체를 반복 분석함 | 소스 해시는 매번 다시 확인하고, 정확히 같은 해시 집합의 AST 분석만 재사용합니다. |
| 배포본에 새 테스트와 동결 계약 fixture가 누락됨 | `test_*.py`, 브라우저 검사, 허용한 fixture JSON을 함께 배포합니다. |

실제 48,137개 평가 자료로 로컬 참조 결과를 생성한 시험에서는 약 14.8초가 걸렸고 WAV 복사는 0개였습니다. 이는 해당 컴퓨터의 실측이며 다른 환경의 시간을 보장하지 않습니다. 원본 음원이 보존돼 있어야 재생할 수 있습니다.

## 정리 기준

- 사용하지 않는 프로토타입과 고아 UI·테스트·문서·설정·예시 파일 1,560개, 약 92.7MB를 제거했습니다. 재생성 가능한 중복 빌드와 시험 캐시도 정리했습니다.
- 삭제 요청한 이전 두 프로젝트는 등록 목록과 전용 자료 약 23.7GB를 함께 제거했습니다. 현재 프로젝트에서 해당 경로를 참조하지 않는지 먼저 확인했으며, 공유 다운로드·모델 캐시·실행 환경은 유지합니다.
- 오래된 설정 원문 87개와 과거 패치 1개는 증빙 ZIP의 모든 항목을 원문 SHA-256과 대조한 뒤 실행 소스에서 분리했습니다. 현재 프로젝트의 보호 파일 81개와 비교실·저장 위치 지침은 정리 전후 해시가 같습니다.
- 현재 학습 결과의 음원·모델·판정·설정·해시 증명은 유지합니다. 보존된 계약에 필요한 호환 처리와 최종 실험 증거는 단순히 오래됐다는 이유로 지우지 않습니다.
- 검증 범위와 최종 검사 결과는 [검수 기록](VALIDATION.md), 화면의 세부 기준은 [레이아웃 기준](WEB_LAYOUT.md)을 참고하세요.
