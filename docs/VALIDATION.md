# 설치·실행 검수 기록

이 문서는 **라이브러리 기능이 작동하는지 확인한 범위**를 설명합니다. 호출어를 얼마나 잘 인식하는지는 별도의 모델 평가 결과로 확인합니다.

## 확인한 기능

| 영역 | 확인 내용 |
| --- | --- |
| 설치 | 별도 폴더에 설치한 패키지로 명령과 API 실행 |
| 음성 생성·검수 | 합성 음색 재사용, 호출어 단독 생성, 검수 결과 저장, 중단 후 이어 생성 |
| 공개 자료 | 다운로드 재개, 파일 크기·해시 확인, 손상 파일 거부 |
| 데이터 준비 | 학습·평가 자료 분리, 승인 자료 확인, 원본 수 × 증강 횟수 검증 |
| 학습 | 작은 시험 자료로 실제 학습, 중단·재개, ONNX 모델 파일 생성 |
| 평가 | 감지 기준 비교, 최종 평가 잠금, 실제 채점 오디오와 결과 화면의 일치 |
| 표본 모델 | 제공 모델 파일의 해시와 호출 결과 재현 |
| 결과 사이트 | 오디오 연속 재생, 소음 수준 선택, 일시정지 |

## 0.3.0 게시 전 결과

- 전체 기능 시험 **57개 통과**.
- 별도 폴더에 설치한 배포 패키지 시험 **54개 통과**. 개발 중 과거 구현과 비교하는 시험 3개는 이 설치 시험에서 제외했습니다.
- 공개 소음 파일의 실제 다운로드와 해시 확인, 예시 모델 파일 및 결과 사이트의 오디오 확인을 수행했습니다.
- 설치용 패키지와 소스 압축 파일을 만들 수 있는지 확인했습니다.

기계적으로 읽을 수 있는 기록은 [publication_checks.json](../validation/publication_checks.json)에 있습니다. 이후 커밋의 자동 검사 결과는 [GitHub Actions](https://github.com/zzorbit/openwakeword-korean/actions)에서 확인하세요. 자동 검사는 Python 3.12의 Windows·Linux 환경에서 실행합니다.

## 이 검사로 알 수 없는 것

작은 시험 자료로 학습이 끝났다는 사실만으로 새 호출어의 호출 성공률이 입증되지는 않습니다. 자동 검사에서도 대규모 TTS 생성이나 여러 사람의 실제 호출 시험을 매번 수행하지 않습니다.

표본 모델의 확인된 성능과 평가 범위는 [모델 설명서](../korean_openwakeword/resources/sample_chunsik/MODEL_CARD.md)에 있습니다. 새 호출어는 [학습 가이드](LIBRARY_GUIDE.md)의 개발용 평가와 독립 최종 평가를 진행하세요. OS·GPU·마이크가 달라진 환경의 결과는 해당 환경에서 확인해야 합니다.
