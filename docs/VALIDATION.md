# 설치·실행 검수 기록

이 문서는 **라이브러리 기능이 작동하는지 확인한 범위**를 설명합니다. 호출어를 얼마나 잘 인식하는지는 별도의 모델 평가 결과로 확인합니다.

## 확인한 기능

| 영역 | 확인 내용 |
| --- | --- |
| 설치 | 별도 폴더에 설치한 패키지로 명령과 API 실행 |
| 음성 생성·검수 | 합성 음색 재사용, 호출어 단독 생성, 검수 결과 저장, 중단 후 이어 생성 |
| 공개 자료 | 다운로드 재개, 파일 크기·해시 확인, 손상 파일 거부 |
| 데이터 준비 | 학습·평가 자료 분리, 승인 자료 확인, 원본 수 × 증강 횟수 검증 |
| 학습 | 작은 시험 자료로 실제 학습, 중단·재개, ONNX 모델 파일 생성 |
| 평가 | 감지 기준 비교, 최종 평가 잠금, 실제 채점 오디오와 결과 화면의 일치 |
| 표본 모델 | 제공 모델 파일의 해시와 호출 결과 재현 |
| 결과 사이트 | 오디오 연속 재생, 소음 수준 선택, 일시정지 |

## 0.9.1 자료 준비 점검

세 규모의 설정·다운로드·준비·학습·평가 연결을 점검했습니다. 기본 학습·공통 평가 자료의 원본 주소 14곳에서 HTTP 200 응답을 확인했으며, 이는 전체 파일 다운로드나 해시 검증 완료를 뜻하지 않습니다.

동작 확인용·시험 모델용의 FMA 준비에서 공식 `tracks.csv`(260,414,445 bytes)보다 작았던 200MiB 해제 한도를 수정했습니다. 필요한 CSV 한 개만 최대 512MiB 범위에서 선택 추출하며 다른 대형 표는 추출하지 않습니다. 세 규모의 작은 시험 자료를 포함한 자료 준비 검사 **28개가 통과**했습니다. 실제 대형 CSV를 시험마다 새로 만드는 대신 공식 크기의 한도와 선택 추출 범위를 검증합니다.

**시험·상용 규모 전체의 웹 자동 공급은 미완료입니다.** 웹은 일반 특징 2,000시간·한국어 원본 1시간을 기본으로 준비하며 추가 목표량은 출처별 명령으로 받은 원본을 연결해야 합니다. 공통 평가 경로는 구현돼 있지만 전체 30시간 준비·112,000회 채점의 실규모 검증과 독립 Final 자동 확보는 완료하지 않았습니다. README와 계획에도 이 범위를 명시했습니다.

상세 범위와 해시는 [0.9.1 검증 기록](../validation/publication_checks_091.json)에 있습니다. 이번 수정에서 별도 wheel 설치는 반복하지 않았으며, 배포 구조가 같은 0.9.0의 설치 검증을 재사용합니다.

## 0.9.0 게시 전 결과

- 관련 Python 기능 시험 **303개 통과**, 권한 제한 시험 1개 생략. 웹 JavaScript 시험 **32개**가 통과했습니다. ZIP64·곡 내부 이어받기·손상 및 서버 변경 차단·용량 상한·기존 다운로드 경로를 포함합니다.
- 실제 FMA 서버에서 원곡 한 개 **5,880,088 bytes·약 145초**를 선택 다운로드하고 CRC32·SHA-256·음원 헤더를 확인했습니다. 같은 곡을 1MiB에서 중단한 뒤 남은 부분만 이어받아 원본 해시가 같은지 확인했습니다. 완료 곡과 완료 기록은 재실행해도 보존했습니다.
- 실제 제공자 목록으로 고정한 1,000시간 선곡은 **13,333곡·제공자 시간 1,000.067시간**, 원곡 전송 예상량 **약 108.01GiB**입니다. 고정 예비 648곡은 실제 길이 부족분이 있을 때만 사용합니다. 선곡 확인만 수행했으며 1,000시간 원곡을 내려받은 결과가 아닙니다.
- 별도 폴더에 wheel을 설치해 새 명령·원곡 재사용·웹 리소스·출처 구성을 확인했습니다. 의존 패키지는 검증 환경의 설치본을 재사용했습니다. 실제 브라우저에서도 선택 다운로드 안내를 확인했습니다.

상세 범위와 해시는 [0.9.0 검증 기록](../validation/publication_checks_090.json)에 있습니다. 부분 다운로드는 전체 ZIP의 공식 SHA1을 검증하지 않습니다. 전체 자료 확보·내용 승인·정식 재학습·새 성능 평가·독립 Final은 수행하지 않았습니다.

## 0.8.1 게시 전 결과

- 변경 경로의 Python 기능 시험 **173개 통과**, 권한 제한 시험 1개 생략. 웹 JavaScript 시험 **30개**가 통과했습니다. 이전 0.8.0의 전체 검사와 별도로 집계합니다.
- 일반 비호출의 새 구성인 AudioSet 3,000시간·MLS 3,000시간·FMA full 1,000시간과 한국어 3,000시간을 CLI·실제 웹 화면·별도 설치 wheel에서 확인했습니다. 이전 v1 화면과 FMA large 다운로드 경로도 유지합니다.

- 45초짜리 시험 원본을 준비해 실제 전체 길이로 집계하는지 확인했습니다. FMA full을 large의 30초 음원으로 처리하지 않으며, 원본·곡 ID·이용조건을 보존합니다. 이 파일은 기능 검증용이며 공개 음악을 검수·승인한 수량에 넣지 않습니다.

상세 범위와 해시는 [0.8.1 검증 기록](../validation/publication_checks_081.json)에 있습니다. 자료 목표·다운로드 기능을 수정한 변경이며 전체 10,000시간 확보·내용 승인·정식 재학습·새 성능 평가·독립 Final은 수행하지 않았습니다.
