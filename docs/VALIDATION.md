# 설치·실행 검수 기록

이 문서는 **라이브러리 기능이 작동하는지 확인한 범위**를 설명합니다. 호출어를 얼마나 잘 인식하는지는 별도의 모델 평가 결과로 확인합니다.

## 확인한 기능

| 영역 | 확인 내용 |
| --- | --- |
| 설치 | 별도 폴더에 설치한 패키지로 명령과 API 실행 |
| 음성 생성·검수 | 합성 음색 재사용, 호출어 단독 생성, 검수 결과 저장, 중단 후 이어 생성 |
| 공개 자료 | 다운로드 재개, 파일 크기·해시 확인, 손상 파일 거부 |
| 데이터 준비 | 학습·평가 자료 분리, 승인 자료 확인, 원본 수 × 증강 횟수 검증 |
| 학습 | 작은 시험 자료로 실제 학습, 중단·재개, ONNX 모델 파일 생성 |
| 평가 | 감지 기준 비교, 최종 평가 잠금, 실제 채점 오디오와 결과 화면의 일치 |
| 표본 모델 | 제공 모델 파일의 해시와 호출 결과 재현 |
| 결과 사이트 | 오디오 연속 재생, 소음 수준 선택, 일시정지 |

## 0.5.2 게시 전 결과

- 별도 폴더에 설치한 패키지에서 기능 시험 **703개 통과**, 권한 제한 시험 1개 생략, 내부 과거 구현 대조 시험 5개 제외. 웹 화면 JavaScript 시험은 15개, 마이크 시험은 14개 통과했습니다.
- 공개 평가 음원 **40개 / 34,126,890 bytes**의 실제 파일·변환·기술 검사를 확인했습니다. 추가 한국어 현장 음원은 6개이며 5개 세부 유형으로 구분합니다.
- 실제 배경 40개와 기존 합성 발화 1개를 재사용해 시험 WAV **1,600개**를 만들고, 모든 원본의 사용과 SNR·진폭을 검사했습니다. 최대 SNR 오차는 **0.001207 dB**였습니다. 독립 호출어 100개의 인식 성능을 평가한 수치는 아닙니다.
- 이전 실제 검수·폐기 판단 재사용, 신규 미청취 자료의 자동 승인 차단, 15초 대표 구간과 원본 전체 청취의 구분, 학습 자료 혼입 차단을 확인했습니다. 설치판 HTTP와 실제 브라우저에서 자료 구성·표시도 확인했습니다.

코드·카탈로그 해시와 검증 범위는 [0.5.2 검증 기록](../validation/publication_checks_052.json)에 있습니다. 새 공개 음원의 사람 청취·사용 승인은 0개이며, 대규모 재학습이나 독립 Final 평가는 수행하지 않았습니다.

## 0.5.1 게시 전 결과

- 별도 폴더의 설치 패키지에서 기능 시험 **691개 통과**, 권한 제한 시험 1개 생략, 내부 과거 구현 대조 시험 5개 제외. 웹 화면·마이크 JavaScript 시험은 각각 **14개 통과**했습니다.
- 공개 평가 음원 34개를 실제로 내려받아 출처·크기·SHA256·변환·기술 검사를 확인했습니다. 원본 10개에만 resampling headroom 감쇠를 기록했고, 사람 청취나 실제 사용 승인은 하지 않았습니다.
- 기존 합성 호출 음성 1개를 100개 구성 slot으로 재사용해 실제 배경 35개로 WAV **1,600개**를 만들었습니다. 새 환경음 20개·10종과 음악/전자음 14개·9종을 모두 사용했고, 저장 WAV의 최대 SNR 오차는 약 **0.001125 dB**, clipping은 0이었습니다. 이 수량은 100개 독립 발화의 성능 평가가 아닙니다.
- 소음 원본·종류 균형, 같은 구간의 SNR 비교, 중복 원본 비중 억제, 단발 충격음 배치, 평가 전용 동의, 과거 실험 보존, 미시작 프로젝트 업데이트를 검사했습니다. 작은 실제 CNN 3개 학습·ONNX·채점·결과 사이트 통합도 포함합니다.

검증 범위와 코드·카탈로그 해시는 [0.5.1 검증 기록](../validation/publication_checks_051.json)에 있습니다. 대규모 재학습·새 호출어의 성능 보증·독립 Final 평가는 포함하지 않습니다.

## 0.5.0 게시 전 결과

- 별도 폴더의 설치 패키지에서 기능 시험 **643개 통과**. Windows 심볼릭 링크 권한 시험 1개는 생략하고, 내부 과거 구현 대조 시험 5개는 제외했습니다.
- 웹 학습 화면 JavaScript 시험 **13개**, 마이크 처리 시험 **14개**를 통과했습니다. Chrome의 데스크톱·모바일 너비에서도 화면을 확인했습니다.
- 작은 절차 검증용 음원으로 실제 특징 추출, CNN 모델 3개의 학습·ONNX 내보내기, 17개 오디오의 채점, 단일 모델·앙상블 순위와 실제 채점 WAV 결과 화면까지 확인했습니다. 이 시험의 학습량은 모델당 1회이며 인식 성능을 평가한 자료는 아닙니다.
- Windows의 실제 Python 자식 프로세스 추적, 중복 실행 방지, 중단·재개, 검수 답변과 승인 범위, 추가 자료 연결을 확인했습니다. 기존 보라야 자료 25개와 표본 모델·평가 WAV 45개의 내용은 그대로 유지했습니다.
- wheel과 소스 압축 파일에 웹 화면·실행 도우미·가이드가 포함되는지 확인했습니다. 대량 공개 자료 다운로드·Qwen 생성·독립 Final 평가는 이번 기능 시험에서 새로 실행하지 않았습니다.

상세 범위와 설치 패키지의 코드 해시는 [0.5.0 검증 기록](../validation/publication_checks_050.json)에 있습니다.

## 0.4.0 게시 전 결과

- 새 가상환경에 일반 wheel로 설치한 기능 시험 **512개 통과**. Windows 심볼릭 링크 권한이 필요한 시험 1개는 생략했고, 내부 과거 코드 대조 시험 5개는 공개 설치 시험에서 제외했습니다. 라이브러리는 전부 설치한 패키지에서 가져왔으며 내부 개발 모듈을 사용하지 않았습니다.
- 마이크 화면·PCM 전달·중지 및 오류 처리의 별도 JavaScript 시험 **14개 통과**. 이 자동 시험에서 실제 마이크를 열거나 개인 음성을 녹음하지 않았습니다.
- 실제 AudioSet 음원 685개의 출처·해시·헤더를 확인하고 작은 시험 분량에 필요한 4개만 변환했습니다. 같은 명령으로 재개해도 입력·출력 파일이 유지됐습니다. 검수 큐 준비까지만 시험했으며 새 내용 승인은 하지 않았습니다.
- 기존 보라야 평가 1,603개에서 단일 후보를 선택해 점수와 결과를 그대로 재사용했습니다. 실제 ONNX의 대표 200프레임에서도 점수와 감지 시각이 같았습니다. 운영 모델 선택이나 Final 승인을 바꾸지는 않았습니다.
- 대량 자료의 순차 처리 전후에 감사 결과와 Positive R1/R3·한국어 비호출 R1의 PCM·특징 파일·중단 후 재개 결과가 같았습니다. 기존 완료 캐시도 검증했습니다.
- Qwen 도구의 새 설치·import와 PyTorch/torchaudio 2.8.0 조합을 확인했습니다. 표본 모델·평가 WAV의 해시, 문서 링크, wheel·소스 압축 파일도 검사했습니다.

검증 범위와 수치는 [0.4.0 검증 기록](../validation/publication_checks_040.json)에 있습니다. 대규모 재학습이나 독립 최종 성능 시험을 새로 수행했다는 뜻은 아닙니다.

## 0.3.0 게시 전 결과

- 전체 기능 시험 **57개 통과**.
- 별도 폴더에 설치한 배포 패키지 시험 **54개 통과**. 개발 중 과거 구현과 비교하는 시험 3개는 이 설치 시험에서 제외했습니다.
- 공개 소음 파일의 실제 다운로드와 해시 확인, 예시 모델 파일 및 결과 사이트의 오디오 확인을 수행했습니다.
- 설치용 패키지와 소스 압축 파일을 만들 수 있는지 확인했습니다.

기계적으로 읽을 수 있는 기록은 [publication_checks.json](../validation/publication_checks.json)에 있습니다. 이후 커밋의 자동 검사 결과는 [GitHub Actions](https://github.com/zzorbit/openwakeword-korean/actions)에서 확인하세요. 자동 검사는 Python 3.12의 Windows·Linux 환경에서 실행합니다.

## 이 검사로 알 수 없는 것

작은 시험 자료로 학습이 끝났다는 사실만으로 새 호출어의 호출 성공률이 입증되지는 않습니다. 자동 검사에서도 대규모 TTS 생성이나 여러 사람의 실제 호출 시험을 매번 수행하지 않습니다.

표본 모델의 확인된 성능과 평가 범위는 [모델 설명서](../korean_openwakeword/resources/sample_chunsik/MODEL_CARD.md)에 있습니다. 새 호출어는 [학습 가이드](LIBRARY_GUIDE.md)의 개발용 평가와 독립 최종 평가를 진행하세요. OS·GPU·마이크가 달라진 환경의 결과는 해당 환경에서 확인해야 합니다.
