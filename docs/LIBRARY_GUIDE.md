# 한국어 호출어 학습 가이드

새 호출어는 웹 학습 화면에서 만들고 평가합니다. Windows에서는 `scripts/Start-Web.cmd`로 열고, 터미널에서 설치했다면 `koww web`으로 엽니다. 설치와 화면 동작은 [웹 학습 안내](WEB_GUIDE.md)에 있습니다.

## 시작 전에 알아둘 용어

| 용어 | 의미 |
| --- | --- |
| Positive | 인식해야 할 호출어 음성 |
| Negative | 호출어가 아닌 대화·음악·환경음 |
| Hard Negative(유사어) | 호출어와 발음이 비슷하지만 다른 표현. 학습 정답은 비호출 |
| 참조 음성 | Qwen TTS가 음색을 따라 생성할 때 사용하는 합성 음성 |
| Feature(특징) | 음성을 모델이 학습할 수 있는 숫자 배열로 바꾼 자료 |
| 개발용 평가(Development) | 모델과 감지 설정을 고를 때 사용하는 평가 |
| 최종 평가(Final) | 모델과 설정을 확정한 뒤 별도 자료로 확인하는 평가 |

**호출어는 단독으로 생성**합니다. 뒤에 명령을 붙이지 않으며, 개인의 실제 호출 녹음은 학습·설정 조정·TTS 참조에 사용하지 않습니다.

## 1. 학습 설정 만들기

**호출어 입력 → 학습 도구 준비 → 학습 규모 선택 → 준비 자료** 순으로 진행합니다. CPU 또는 NVIDIA GPU와 [학습 규모](../README.md#학습-규모-선택)를 선택합니다. **자료 다운로드**에서 다운로드와 전처리를 시작할 수 있습니다.

새 학습은 `models/model_0001`처럼 번호가 붙은 폴더에 저장됩니다. **설정 → 작업한 호출어**에서 기존 학습을 선택하고 멈춘 단계부터 재개합니다. 학습 설정은 `project.json`에, 실제 작업 결과와 증빙은 단계별 결과 폴더에 기록합니다.

## 2. 기준 목소리 준비·자동 검사

웹은 성별 2개와 연령 5개(어린이·청소년·청년·중년·노년)를 조합한 10분류를 학습용·공통 평가용에 각각 둡니다. **기준 목소리 생성**에서 학습용 후보는 분류당 10개, 30개, 100개 중 선택한 규모에 맞춰 준비하고, 공통 평가용은 분류당 10개씩 총 100개를 준비합니다. GPU는 10개를 함께 합성하며 검수 화면에는 5개씩 표시합니다. 후보마다 해당 연령의 **음높이·울림·음색·속도·억양** 옵션과 시드를 무작위로 조합하고 그 계획을 저장합니다. 현재 영어 설명의 기준 연령은 약 8·16·27·47·80세이며, 실제 성별·연령이나 음색 차이를 보장하지 않습니다.

**기준 목소리 검수**는 남성 어린이→청소년→청년→중년→노년, 이어 여성도 같은 순서로 진행합니다. 요청한 성별·연령에 맞고 서로 다른 목소리로 들리는 후보를 선택하세요. 학습용은 **분류당 2·10·50개**, 공통 평가용은 **분류당 3개**가 목표입니다. 카드 5개 중 남은 목표 수를 넘지 않는 범위에서 원하는 만큼 고를 수 있고, 부족하면 `+`로 같은 분류의 후보 10개를 추가합니다. 사전 후보 수와 최종 선택 수는 별개입니다.

후보를 끝까지 듣지 않아도 선택할 수 있지만 선택만으로 청취 완료가 기록되지는 않습니다. 모든 분류의 선택이 확정되면 후보와 화자 슬롯의 연결·음원 해시를 고정해 기준 목소리 은행으로 사용합니다. 자동 기술 검사, 사람의 후보 선택, 실제 재생 기록을 따로 보존합니다. 후보 선택은 이후 모든 발화의 발음이나 다수 화자 성능을 보증하지 않습니다.

## 3. 목소리별 호출어 발음 검수하기

**호출어 샘플 생성**에서 확정한 학습용·공통 평가용 목소리마다 샘플을 만든 뒤 **호출어 발음 사전 검수**를 진행합니다. 샘플을 통과한 목소리로 **호출어 음성 생성**을 진행하고 **호출어 발음 검수**에서 본생성 음원을 목소리마다 대표 1개씩 확인합니다. 두 검수 각각에서 동작 확인용 50개, 시험 모델용 130개, 상용 모델용 530개를 확인합니다.

**유사어 입력**에서 발음이 비슷한 다른 표현을 넣습니다. **유사어 음성 생성**에서 문구마다 학습용 목소리로 음원을 만든 뒤 **유사어 발음 검수**에서 문구마다 대표 1개를 듣습니다. 부적합 판정한 문구의 음원은 학습 목록에서 빠집니다. 작업이 멈춘 뒤 웹에서 재개하면 검증한 음원과 검수 기록을 이어서 사용합니다.

## 4. 비호출·소음·잔향 자료

제공 학습·평가 배경 자료는 웹에서 자동 검사와 연결을 진행합니다. 직접 추가한 자료는 제공 자료와 구분해 대표 내용 검수를 마칩니다. 자료의 출처, 이용조건과 준비 목표는 [학습 데이터 안내](DATASETS.md), 저장 목록과 검수 기록의 형식은 [자료 형식](DATA_FORMAT.md)에서 확인할 수 있습니다.

## 5. 증강·학습 및 공통 평가

**증강·특징 추출**에서 호출어 원본 수에 증강 횟수를 곱한 만큼 특징을 만듭니다. **모델 학습**에서 CNN128 모델 3개를 학습하고 ONNX 실행 묶음을 저장합니다. 배치는 일반 비호출 768개, 한국어 비호출 256개, 호출어 100개, 유사어 100개입니다.

**성능 평가**에서 같은 시험 음원으로 단일 모델과 평균 앙상블을 채점합니다. 새 공통 평가 v5는 30개 평가 음색의 호출어 원본 2,000개를 사용합니다. 잔향 없는 32,000회와 대표 원본 500개의 일반·강한 잔향 16,000회를 더한 호출 시험 48,000회, 비호출 시험 30시간을 계획합니다. 표본 수와 실제 채점 시간은 평가 기록에서 확인합니다. [평가 자료](DATASETS.md#성능-평가용-배경-음원)

## 6. 학습 결과 확인

채점과 결과 준비가 끝나면 **다음**을 눌러 [학습 결과](TRAINING_RESULTS_SITE.md)를 엽니다. **모델 비교**에서 기본 감지 기준과 추천 감지 기준을 전환하고, **소음별**과 **음원**에서 조건과 실제 채점 음원을 확인할 수 있습니다. 추천은 저장한 점수를 활용하며 규칙은 [학습 계획](../plan.md#모델별-감지-설정-자동-추천)에 있습니다.

기존 독립 최종 평가 기록은 별도 자료와 동결 설정을 기준으로 해석합니다. 웹의 공통 평가는 개발용 평가입니다. [독립 최종 평가 자료](DATASETS.md#독립-최종-평가-자료)

## 학습한 모델 사용하기

웹에서 완료한 프로젝트의 모델 묶음은 모델 폴더 안의 `models/studio_bundle`에 저장됩니다. 묶음 폴더 안의 `manifest.json`과 모델·공통 특징 추출 파일을 함께 사용합니다.

### 마이크로 모델 시험하기

새로 학습하지 않고도 기본 설치에 포함된 ‘춘식아’ 모델을 마이크로 시험할 수 있습니다. 추가 패키지를 설치하지 않고 실행합니다.

```powershell
koww mic
```

직접 학습한 모델은 `manifest.json`이 있는 모델 묶음 폴더를 지정합니다. 아래 경로를 자신의 웹 학습 결과에 저장된 모델 묶음 폴더로 바꾸세요.

```powershell
koww mic --bundle models/model_0001/models/studio_bundle
```

1. [http://127.0.0.1:8792/](http://127.0.0.1:8792/)을 엽니다. 웹 학습에서는 **마이크 시험**으로 이동합니다. **연결**을 눌러 브라우저에 권한을 주고 마이크를 고릅니다. 새 장치를 연결했으면 **새로고침**으로 목록을 갱신합니다.
2. **시험 시작**을 누릅니다.
3. 준비 표시가 끝난 뒤(기본 2초) 화면에 나온 호출어를 말합니다.
4. **마이크 입력**, **최근 감지**와 각 모델의 점수·감지 횟수·감지 기준을 확인합니다. 모델 3개가 있는 묶음은 세 점수의 평균에 따른 앙상블 결과도 보여줍니다.
5. **중지**를 누르면 마이크 입력을 종료합니다. 다시 시작하면 모델의 입력 이력과 준비 시간이 초기화됩니다.

마이크 시험은 **기존 모델의 반응을 확인하는 기능**입니다. 웹의 **모델별 추천값** 모드는 모델마다 선택된 감지 기준을 적용합니다. 적용할 추천값이 없는 모델에는 기본 감지 기준을 사용합니다. **직접 설정**에서는 임계값·연속 감지 수를 같은 값으로 바꿔 비교할 수 있습니다. 개별 `mic` 명령은 지정한 모델 묶음의 설정으로 시작합니다. 시험용 변경값은 메모리에서만 사용하고 모델·평가 기록을 바꾸지 않습니다. 초기 준비·재감지 간격과 약 2초 입력 범위는 유지합니다. 개인 음성은 녹음 파일로 저장하지 않으며, 학습·자동 추천·TTS 참조로 사용하지 않습니다.

자동 음량 보정은 하지 않습니다. 마이크 시험을 시작할 때 브라우저에 자동 음량 조절·소음 억제·에코 제거를 끄도록 요청합니다. 장치나 운영체제에서 별도로 적용하는 음성 처리는 다를 수 있습니다.

서버가 실행되는 동안 터미널을 열어 두세요. 종료는 **Ctrl+C**, 재실행은 같은 `mic` 명령입니다. 포트를 바꾸려면 `--port 8794`처럼 지정합니다. 권한이 거부되면 브라우저의 사이트 권한에서 마이크를 허용하고, 다른 장치가 선택되었거나 입력이 없다면 마이크를 다시 선택해 시작하세요.

### Python에서 직접 학습한 모델 사용하기

```python
from korean_openwakeword import WakeWordDetector

detector = WakeWordDetector("models/model_0001/models/studio_bundle")
result = detector.predict_file("test.wav")
print(result["events"])
```

입력은 16kHz·모노·16비트 PCM WAV입니다. 기본 설정에서는 시작 후 2초의 준비 구간이 필요합니다. 실시간 입력은 같은 형식의 80ms 음성 배열(1,280개 샘플)을 `process`에 전달하고 새 세션에서는 `reset`합니다.

모델 구조·배치·VAD(음성 구간 감지)·노이즈 제거의 지원 범위와 [이용조건](../THIRD_PARTY_NOTICES.md)을 확인하세요.
