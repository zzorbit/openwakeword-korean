# 저장 위치 안내

학습 자료를 둘 드라이브와 폴더는 사용자가 선택합니다. **SSD와 HDD 모두 사용할 수 있습니다.** 자료가 들어갈 실제 위치와 여유 공간을 먼저 확인하세요.

## 무엇이 어디에 저장되나요?

| 항목 | 기본 위치 |
| --- | --- |
| 생성 음성·학습 데이터·학습 결과 | `koww init --output`으로 만든 프로젝트 폴더 |
| 공개 자료 다운로드 | 다운로드 명령의 `--output`으로 지정한 파일 |
| 모델 다운로드·임시 파일 | 프로젝트 폴더의 `cache` |
| 설치 스크립트를 사용한 다운로드 캐시·임시 파일 | 저장소 폴더의 `storage/runtime_cache` |

프로젝트별 저장 위치는 다음 명령으로 확인합니다.

```powershell
koww storage --project projects/bora/project.json
```

## 설치할 때의 저장 위치

Windows PowerShell에서 저장소 폴더로 이동한 뒤, 패키지를 설치하기 전에 실행하세요.

```powershell
. .\scripts\Use-ProjectStorage.ps1
```

이 스크립트는 설치 파일·모델 다운로드 캐시·임시 파일을 저장소 안에 모아 저장하도록 설정합니다. **현재 PowerShell 창과 그 창에서 실행한 프로그램에만 적용**됩니다. 창을 닫았다가 다시 열면 필요한 작업 전에 다시 실행하세요. 시스템 전체 설정을 바꾸지는 않습니다.

## 여러 호출어에서 다운로드 캐시 공유하기

여러 프로젝트가 같은 Qwen 모델을 내려받지 않도록 캐시 위치를 지정할 수 있습니다. 다음은 저장소의 `shared/cache`를 사용하는 예시입니다.

```powershell
$env:KOWW_CACHE_ROOT = Join-Path (Get-Location).Path 'shared/cache'
koww storage --project projects/bora/project.json
```

`Use-ProjectStorage.ps1`도 이 값을 설정하므로, 공유 캐시를 직접 지정하려면 **스크립트를 실행한 다음** 위 명령을 사용하세요. 공개 음성·소음 자료는 `shared/`에 한 번 내려받고 각 프로젝트의 자료 목록에서 연결해 재사용할 수 있습니다.

## 대규모 자료의 중복 저장 줄이기

새 웹 프로젝트는 `automatic_v2` 정책으로 **대규모 AudioSet unbalanced·MLS·YODAS2의 임시 다운로드 묶음**을 관리합니다.

1. 묶음 하나를 내려받고 제공자 해시를 확인합니다.
2. 안전하게 해제한 모든 파일의 SHA-256과 완료 기록을 확인합니다.
3. 원본 음원·메타데이터·검증 기록을 보존하고, 새 관리 영역의 해당 임시 묶음만 정리합니다.

검증 실패·중단 중에는 묶음을 정리하지 않습니다. 재개 시 보존한 원본과 기록을 다시 검사하므로 완료한 원본을 재다운로드할 필요가 없습니다. 기존 사용자 다운로드·외부 파일·`automatic_v1` 캐시는 자동 삭제하지 않습니다. 동작 확인용·시험 모델용의 공식 예제 소음과 공통 평가 기본 묶음도 기존 방식으로 보존합니다. FMA full은 이미 필요한 원곡만 선택 다운로드하므로 이 정책에서도 그대로 사용합니다.

**저장 용량을 줄이는 변경이며 다운로드 전송량은 줄지 않습니다.** 원본 음원 바이트, 학습용 변환 WAV, 증강·특징 계산과 모델 학습 설정은 유지합니다. 음질을 낮추거나 자료 시간을 줄이지 않습니다.

상용 기본값인 비호출 10,000시간·호출어 100,000개·R5의 저장 예산은 다음과 같습니다. TB·GB는 각각 10¹²·10⁹바이트이며 화면은 TiB·GiB로 표시합니다.

| 항목 | 기존 보관 방식 | 새 보관 방식 |
| --- | ---: | ---: |
| 대규모 원본·다운로드 묶음 | 약 4.865TB | 원본 약 2.585TB |
| 학습용 변환 음원 | 약 1.152TB | 동일 |
| 호출어·비호출 특징 | 약 114GB | 동일 |
| 기본 평가 자료·작업 여유 | 약 56GB | 동일 |
| 대규모 임시 묶음 | 위 원본 예산에 포함 | 한 묶음씩 처리·초기 8GiB 예산 |
| **계획 합계** | **약 6.2TB** | **약 3.9TB** |

| 기본 규모 | 개선 전 | 개선 후 |
| --- | ---: | ---: |
| 동작 확인용 | 약 83GB | 약 83GB |
| 시험 모델용 | 약 367GB | 약 296GB |
| 상용 모델용 | 약 6.187TB | 약 3.916TB |

약 2.3TB의 중복 보관 예산을 줄인 계산이며 전체 자료를 내려받은 실측값은 아닙니다. 원본 codec·실제 묶음 크기·QC 보충량에 따라 달라지고, TTS WAV·평가 WAV·체크포인트 등 추가 작업 공간도 필요합니다. 같은 드라이브의 원본 연결에는 하드링크를 우선 사용하며, 이를 지원하지 않아 복사가 필요하면 해당 공간도 추가로 계산합니다. 8GiB는 임시 작업 예산이며 모든 묶음의 최대 크기를 보장하는 값은 아닙니다. 실제 선정한 묶음마다 다운로드·해제·변환에 필요한 공간을 다시 확인합니다. 원본을 제외한 최소량을 전체 필요량으로 해석하지 않습니다.

## 용량 확인과 자료 이동

압축 파일과 압축 해제한 음원, 증강 특징 파일, 평가 오디오는 각각 공간을 사용합니다. 설치된 Python의 위치와 학습 자료의 위치는 별개입니다.

폴더를 옮길 때는 **원본 보존 → 복사 → 파일 크기·SHA256 확인 → 설정의 경로 확인 → 새 위치에서 사용 확인** 순서로 진행하세요. 확인이 끝나기 전에 원본을 지우지 않습니다. 실행 중인 학습이 사용하는 파일은 이동하거나 정리하지 않습니다.

일시적으로 더 빠른 드라이브를 사용할 때도 용량 한도와 작업 후 정리 방법을 정해 두세요. 라이브러리는 성능을 이유로 자료를 다른 드라이브에 자동 복사하지 않습니다.

전체 학습 절차는 [호출어 학습 가이드](LIBRARY_GUIDE.md)를 참고하세요.
