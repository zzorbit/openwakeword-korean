# 저장 위치 안내

학습 자료를 둘 드라이브와 폴더는 사용자가 선택합니다. **SSD와 HDD 모두 사용할 수 있습니다.** 자료가 들어갈 실제 위치와 여유 공간을 먼저 확인하세요.

## 무엇이 어디에 저장되나요?

| 항목 | 기본 위치 |
| --- | --- |
| 생성 음성·학습 데이터·학습 결과 | `koww init --output`으로 만든 프로젝트 폴더 |
| 공개 자료 다운로드 | 다운로드 명령의 `--output`으로 지정한 파일 |
| 모델 다운로드·임시 파일 | 프로젝트 폴더의 `cache` |
| 설치 스크립트를 사용한 다운로드 캐시·임시 파일 | 저장소 폴더의 `storage/runtime_cache` |

프로젝트별 저장 위치는 다음 명령으로 확인합니다.

```powershell
koww storage --project projects/bora/project.json
```

## 설치할 때의 저장 위치

Windows PowerShell에서 저장소 폴더로 이동한 뒤, 패키지를 설치하기 전에 실행하세요.

```powershell
. .\scripts\Use-ProjectStorage.ps1
```

이 스크립트는 설치 파일·모델 다운로드 캐시·임시 파일을 저장소 안에 모아 저장하도록 설정합니다. **현재 PowerShell 창과 그 창에서 실행한 프로그램에만 적용**됩니다. 창을 닫았다가 다시 열면 필요한 작업 전에 다시 실행하세요. 시스템 전체 설정을 바꾸지는 않습니다.

## 여러 호출어에서 다운로드 캐시 공유하기

여러 프로젝트가 같은 Qwen 모델을 내려받지 않도록 캐시 위치를 지정할 수 있습니다. 다음은 저장소의 `shared/cache`를 사용하는 예시입니다.

```powershell
$env:KOWW_CACHE_ROOT = Join-Path (Get-Location).Path 'shared/cache'
koww storage --project projects/bora/project.json
```

`Use-ProjectStorage.ps1`도 이 값을 설정하므로, 공유 캐시를 직접 지정하려면 **스크립트를 실행한 다음** 위 명령을 사용하세요. 공개 음성·소음 자료는 `shared/`에 한 번 내려받고 각 프로젝트의 자료 목록에서 연결해 재사용할 수 있습니다.

## 대규모 자료의 중복 저장 줄이기

새 웹 프로젝트는 `automatic_v3`의 `canonical_flac_only_v1` 정책을 사용합니다. **공개 학습 비호출·소음·잔향의 학습용 변환본을 16kHz 모노 PCM16 무손실 FLAC으로 보관**합니다. 대규모 AudioSet·MLS·FMA full·YODAS2의 새 원본은 검증 후 정리하고, 공식 예제 소음·MIT RIR의 공유 기본 다운로드와 묶음은 보존합니다.

1. 제공자 원본을 내려받아 크기·해시와 출처를 확인합니다.
2. 기존 전처리와 같은 학습용 PCM을 만들고 FLAC에 저장합니다.
3. FLAC을 다시 읽어 PCM 값·길이·해시가 같은지 확인하고 완료 기록을 남깁니다.
4. 검증한 새 대규모 자료의 전용 원본·임시 묶음과 중복 변환 WAV만 정리합니다.

검증 실패·중단 중에는 정리하지 않습니다. 완료한 FLAC과 원본 ID·원본 해시·제공자 정보·이용조건·변환 기록을 보존하고, 재개 시 확인해 재사용합니다. 기존 사용자 자료·외부 파일·이전 캐시·완료 기록을 자동 변환하거나 삭제하지 않습니다. 기존 검사에서 거부한 음원과 공유 중인 원본도 남깁니다. 생성 TTS와 평가 WAV도 이번 변경 대상이 아닙니다. `automatic_v1`·`automatic_v2` 프로젝트와 개별 다운로드 명령은 기존 보관 방식을 유지합니다.

**FLAC 보관은 학습 입력을 유지하고 중복 보관만 줄입니다.** 기존 학습용 PCM을 손실 없이 저장하지만 고해상도 원본 자체를 보존하는 방식은 아닙니다. 원본을 다른 전처리 설정으로 다시 변환하려면 재다운로드해야 합니다. 보관 방식만 바꾸면 자료 시간·선정 목록·증강·특징 계산·학습 설정과 다운로드 전송량은 바뀌지 않습니다. 자료 목표 시간을 줄이는 것은 이 보관 방식과 별도의 선택입니다.

상용 기본값은 **비호출 5,000시간·호출어 100,000개·R5**입니다. 같은 FLAC 보관 정책으로 기존 10,000시간 구성과 비교한 참고 예산입니다. TB·GB는 각각 10¹²·10⁹바이트이며 화면은 TiB·GiB로 표시합니다.

| 항목 | 기존 비호출 10,000시간 | 새 비호출 5,000시간 |
| --- | ---: | ---: |
| 비호출 학습 음원(WAV 환산) | 1,152GB | 576GB |
| 비호출 특징 | 110.592GB | 55.296GB |
| 호출어 R5 특징 | 3.072GB | 3.072GB |
| FMA 원곡 임시 공간 | 약 125GB | 약 62.5GB |
| 기본 평가 자료 다운로드·작업 여유 | 약 56.3GB | 약 56.3GB |
| **WAV 기준 참고 합계** | **약 1.447TB** | **약 0.753TB** |

새 구성은 AudioSet 1,500시간·MLS 1,500시간·FMA full 500시간·YODAS2 한국어 1,500시간으로, 종전 각 자료의 절반입니다. **약 694GB·48% 감소**하며 호출어 수·R5·모델당 학습량은 유지합니다. 합계는 학습 음원을 FLAC으로 압축하기 전의 WAV 크기를 넣은 **비교용 예산**입니다. 전체 FLAC 압축률을 실측한 필요 용량이나 최소 용량이 아닙니다. 현재 FMA는 선정 곡을 모두 받은 뒤 변환하므로 원곡의 임시 공간도 필요합니다.

이전 10,000시간의 원본 보관 방식으로 계산한 약 3.916TB와 FLAC 방식의 약 1.447TB는 과거 구성의 비교값이며 현재 기본 필요량이 아닙니다.

| 기본 규모 | WAV 기준 참고 예산 |
| --- | ---: |
| 동작 확인용 | 약 83GB |
| 시험 모델용 | 약 176GB |
| 상용 모델용 | 약 0.753TB |

**학습부터 공통·독립 최종 평가까지 진행할 새 프로젝트에는 약 1.0~1.2TB의 여유 공간을 권장**합니다. 위 0.753TB에 TTS·재시도 음원, Qwen·학습 도구, 평가 WAV·점수·모델과 보충량을 더한 계획 예산입니다. 독립 최종 평가 100시간의 원본 다운로드 묶음은 출처에 따라 달라지므로 실측 총량이나 보장된 상한은 아닙니다. 기존 프로젝트·백업 보존 공간은 별도입니다.

실제 FLAC 크기는 말소리·음악·환경음의 구성에 따라 달라집니다. 실제 선정한 묶음마다 다운로드·해제·변환 공간을 다시 확인하고, 완료한 FLAC의 크기는 기록에 합산합니다. 기존 자료를 보존하므로 업데이트만으로 현재 사용 공간이 줄어들지는 않습니다.

### 실제 표본의 압축 크기

기존 PCM과 FLAC을 다시 읽은 PCM이 같은지 확인한 표본입니다. 아래 비율은 전체 자료의 예상 압축률이 아닙니다.

| 표본 | 오디오 길이 | PCM 데이터 | FLAC 파일 | PCM 대비 크기 |
| --- | ---: | ---: | ---: | ---: |
| MLS 30개 | 459.32초 | 14,698,240B | 7,705,913B | 52.43% |
| FMA 원곡 1개 | 144.90초 | 4,636,908B | 2,977,227B | 64.21% |
| YODAS2 10개 | 4,259.57초 | 136,306,104B | 86,730,397B | 63.63% |

YODAS2는 기존 20개 중 10개가 종전과 같은 클리핑 검사에서 거부됐으며 원본을 보존했습니다. 검사 기준을 완화해 압축 수량을 늘리지 않습니다.

## 용량 확인과 자료 이동

압축 파일과 압축 해제한 음원, 증강 특징 파일, 평가 오디오는 각각 공간을 사용합니다. 설치된 Python의 위치와 학습 자료의 위치는 별개입니다.

폴더를 옮길 때는 **원본 보존 → 복사 → 파일 크기·SHA256 확인 → 설정의 경로 확인 → 새 위치에서 사용 확인** 순서로 진행하세요. 확인이 끝나기 전에 원본을 지우지 않습니다. 실행 중인 학습이 사용하는 파일은 이동하거나 정리하지 않습니다.

일시적으로 더 빠른 드라이브를 사용할 때도 용량 한도와 작업 후 정리 방법을 정해 두세요. 라이브러리는 성능을 이유로 자료를 다른 드라이브에 자동 복사하지 않습니다.

전체 학습 절차는 [호출어 학습 가이드](LIBRARY_GUIDE.md)를 참고하세요.
