# 학습 결과 사이트 사용법

모델 평가가 끝나면 통계와 시험 오디오를 함께 볼 수 있는 사이트를 만듭니다.

## 사이트 만들고 열기

아래는 최종 평가 결과가 `projects/bora/reports/final_v1`에 저장된 경우입니다.

```powershell
koww site --evaluation projects/bora/reports/final_v1 --output projects/bora/reports/final_v1/site
koww serve --directory projects/bora/reports/final_v1/site --port 8791
```

브라우저에서 [http://127.0.0.1:8791/](http://127.0.0.1:8791/)을 여세요. 서버를 실행한 터미널은 열어 두어야 합니다. 이미 만든 사이트를 다시 열 때는 `serve` 명령만 실행하세요.

개발용 평가 결과도 같은 방법으로 볼 수 있습니다. `--evaluation`은 평가 결과 폴더, `--output`은 새로 만들 사이트 폴더입니다.

## 무엇을 확인하나요?

| 화면 | 확인할 내용 |
| --- | --- |
| 채점 요약 | 단일 모델을 호출 성공률이 높은 순서로 비교. 앙상블은 별도로 표시 |
| 후보별 기준 통과 | 단일·앙상블 각각의 통과 여부와 미달·미측정 이유. 선택한 판정 대상도 표시 |
| 조건별 결과 | 조용한 환경, 환경소음, 음악·전자음, 한국어 대화가 겹치는 조건의 성공률 |
| 오호출 | 평가 시간, 오호출 횟수, 시간당 오호출 수 |
| 오디오와 모델 반응 | 실제 채점한 소리를 듣고 감지·누락 결과 확인 |

소음 수준(SNR)을 선택하고 연속 듣기를 시작하면 원본 음성·배경 종류·소음 구간 순서로 재생됩니다. 특정 항목으로 이동하거나 일시정지할 수 있습니다. SNR 값이 낮을수록 호출어에 비해 소음이 큽니다.

오디오 영역에는 실제 시험에 사용한 배경의 원본 수와 세부 종류 수를 표시합니다. 같은 배경을 SNR별로 반복해도 원본 수를 늘려 세지 않습니다. 동작 확인용의 상세 사용 분포는 평가 오디오 준비 폴더의 `noise_coverage.json`에도 기록합니다.

화면은 **채점에 사용한 WAV와 동일한 파일**을 재생하고 다운로드합니다. 듣기용으로만 음량을 바꾼 다른 오디오는 제공하지 않습니다. 시험 오디오 자체를 수정했다면 새 버전으로 다시 평가한 뒤 사이트를 만드세요.

## 결과를 읽을 때

성공률과 함께 실제 호출 횟수와 비호출 평가 시간을 확인하세요. 같은 자료를 여러 모델로 평가했다고 평가 시간이 늘어나지는 않습니다. 개발용·최종 평가, 합성·실제 사람 음성 결과도 구분합니다.

[동봉 참고 화면](../examples/library_demo_site/index.html)은 제공된 소규모 예시 오디오의 결과입니다. 전체 학습 성능이나 새 호출어의 평가 결과를 대신하지 않습니다. 사이트에는 시간별 점수 그래프를 넣지 않고 조건별 결과와 청취에 집중합니다.

평가 순서와 기준은 [학습 가이드](LIBRARY_GUIDE.md)와 [학습 계획](../plan.md)을 참고하세요.
