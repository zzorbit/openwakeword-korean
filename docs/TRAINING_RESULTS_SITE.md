# 학습 결과 사이트 사용법

**성능 평가**에서 채점과 결과 준비를 마치면 **다음**으로 **학습 결과**를 엽니다. 완료한 모델의 결과는 웹의 **설정 → 작업한 호출어**에서 기존 모델을 연 뒤 **학습 결과** 챕터로 돌아가 확인합니다.

## 무엇을 확인하나요?

| 탭 | 확인할 내용 |
| --- | --- |
| 모델 비교 | 단일 모델과 앙상블의 감지율, 시간당 오호출, 반응 시간(P95), 감지 기준 |
| 소음별 | 모델과 공간 울림을 골라 기본 평가의 배경음 종류·SNR별 감지율 확인 |
| 음원 | 시험 음원 재생과 모델별 감지 결과 |

**모델 비교**에서 **기본 감지 기준**은 평가 당시 적용한 임계값과 연속 감지 횟수입니다. 추천 기록이 있으면 **추천 감지 기준**으로 전환할 수 있습니다. 표의 감지 기준 제목을 누르면 설정의 의미와 선택 규칙이 나옵니다. P95는 감지에 성공한 호출의 약 95%가 그 시점까지 감지됐다는 뜻입니다. 값에 ‘전’이 붙으면 발화가 끝나기 전에 감지됐다는 뜻입니다.

**강한 소음·울림**은 보통·강한 울림과 SNR 10·5·0 dB, 배경음 3종을 조합한 18조건에서 감지율을 같은 비중으로 평균합니다. **최악 조건**은 강한 울림과 SNR 0 dB에서 배경음별 감지율을 같은 비중으로 평균합니다. 이전 기록에 필요한 점수가 없으면 값이 비어 있을 수 있습니다.

**음원**은 재생바 위 목록에서 배경 종류, 울림, 소음 크기 순으로 폴더를 열어 고릅니다. 배경음 없는 호출어와 호출어 없는 음원도 같은 목록에 있습니다. 항목이 많은 폴더는 100개 단위 구간으로 열 수 있으며, 재생부의 이전·다음은 선택한 폴더 안에서 이동합니다. SNR이 낮을수록 호출어에 비해 배경음이 큽니다.

화면은 **채점에 사용한 WAV와 동일한 음원**을 재생합니다. 웹 학습 결과를 다시 열 때도 채점 음원이 저장된 작업 폴더를 사용하세요.

## 결과를 읽을 때

새 공통 평가는 세 학습 규모 모두 호출 시험 48,000회와 비호출 시험 30시간을 계획합니다. 감지율을 읽을 때는 실제 표본 수와 채점 시간을 함께 확인하세요. 배경음 사용 분포는 평가 준비 폴더의 `noise_coverage.json`, 공통 평가 자료의 범위는 평가 결과 폴더의 `common_coverage_*.json`에 기록됩니다. 개발용·독립 최종 평가와 합성·실제 사람 음성 결과는 구분해서 읽으세요.

[동봉 참고 화면](../examples/library_demo_site/index.html)은 제공된 소규모 예시 오디오의 결과입니다. 전체 학습 성능이나 새 호출어의 평가 결과를 대신하지 않습니다. 사이트에는 시간별 점수 그래프를 넣지 않고 조건별 결과와 청취에 집중합니다.

평가 순서와 기준은 [학습 가이드](LIBRARY_GUIDE.md)와 [학습 계획](../plan.md)을 참고하세요.
