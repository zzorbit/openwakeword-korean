# Korean openWakeWord

**영어 호출어에 특화된 openWakeWord를 한국어 호출어 전용으로 수정한 라이브러리입니다.**

이 프로젝트는 **[openWakeWord](https://github.com/dscripka/openWakeWord)(David Scripka 및 기여자)를 기반으로 개발한 파생 프로젝트**입니다. 원 프로젝트의 공통 음성 특징 추출 기능을 사용하며, 한국어 Qwen TTS 데이터 생성·소음 증강·판별기 학습·평가·결과 사이트를 위한 절차를 추가했습니다. 원 프로젝트와 별도로 개발·관리합니다.

새 학습의 화면과 검수 흐름, 준비 상태 표시, 결과 페이지 최적화는 [웹 안내](docs/WEB_GUIDE.md)와 [개선 사항 정리](docs/CODE_IMPROVEMENTS.md)를 참고하세요.

설치 후, 동봉된 ‘춘식아’ 예시 모델을 음성 파일이나 실시간 마이크 입력으로 시험할 수 있습니다.

합성 호출 음성의 개발용 평가 결과이며, 상세 조건과 검증 범위는 [표본 모델 설명서](korean_openwakeword/resources/sample_chunsik/MODEL_CARD.md)에 있습니다.

## 설치

### Windows에서 웹 화면 열기

1. Python을 설치합니다. **Python 3.12**를 권장합니다.
2. [저장소 ZIP](https://github.com/zzorbit/openwakeword-korean/archive/refs/heads/main.zip)을 내려받아 작업할 위치에 압축을 풉니다.
3. 압축을 푼 폴더의 `scripts\Start-Web.cmd`를 더블클릭합니다.

첫 실행에는 인터넷 연결이 필요합니다. 실행 파일이 폴더 안에 가상환경(`.venv`)을 만들고 웹 화면에 필요한 패키지를 설치한 뒤 브라우저를 엽니다. 이후에는 같은 파일을 더블클릭하면 설치한 환경을 확인하고 실행합니다. 학습에 필요한 CPU·GPU 도구는 웹 화면의 안내에 따라 선택합니다. [웹 학습 안내](docs/WEB_GUIDE.md)

`Start-Web.cmd` 실행 창을 닫으면 웹 서버가 함께 종료됩니다. 다시 열려면 같은 파일을 실행합니다.

### 터미널에서 설치하기

터미널에서 설치하려면 **Git과 Python 3.10–3.13**을 준비하세요. 아래 명령은 **Windows PowerShell** 기준입니다.

```powershell
git clone https://github.com/zzorbit/openwakeword-korean.git
cd openwakeword-korean
. .\scripts\Use-ProjectStorage.ps1
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install .
python -m pip install openwakeword==0.6.0 --no-deps
koww check
```

`koww check`는 필요한 패키지의 설치 여부·버전과 GPU 사용 가능 여부를 확인합니다. 학습이나 모델 성능 시험을 시작하는 명령은 아닙니다. openWakeWord는 설치 호환성을 위해 위 명령처럼 별도로 설치합니다.

`Use-ProjectStorage.ps1`은 다운로드 캐시와 임시 파일을 저장소 폴더 안에 모아 저장하도록 설정합니다. 저장 위치를 바꾸려면 [저장 위치 안내](docs/STORAGE_POLICY.md)를 참고하세요.

## 웹에서 학습·시험하기

새 호출어의 자료 준비, 생성과 검수, 학습 및 평가는 웹 학습 화면에서 진행합니다. 터미널에서 설치했다면 가상환경에서 다음 명령을 실행하세요.

```powershell
koww web
```

[학습 화면](http://127.0.0.1:8793/)에서 **호출어 입력 → 학습 도구 준비 → 학습 규모 선택 → 준비할 자료 확인** 순으로 진행합니다. 다음으로 넘어가 모델을 만든 뒤, 다운로드 화면에서 **다운로드 시작**을 누르세요. 다운로드·검사·자료 연결을 마치면 **다음**으로 진행합니다. 자료와 결과는 `models/model_0001`, `models/model_0002`처럼 번호가 붙은 폴더에 자동 저장됩니다.

준비할 자료 화면은 왼쪽에 자료 이름과 출처, 오른쪽에 수량과 다운로드 용량을 두 줄씩 표시합니다. 자료 목록은 페이지를 나누지 않고 표시합니다. 학습용·성능 평가용 제목 옆에는 재사용·공유 파일을 제외한 합산 다운로드 용량을 대략 표시하고, 일부 자료의 용량을 모르면 합계 옆에 **미정**을 붙입니다. 제목·목록·이동 버튼을 내용에 맞는 높이로 중앙에 모으고, 행 사이에는 읽기 편한 간격을 둡니다. 작은 창에서는 목록 안에서만 스크롤합니다. 자동 선정 자료는 전송량 추정에 **약**을 붙이고, 공유 파일·재사용 음원·나중에 생성할 음성·미확정 용량은 구별합니다. 이 수치는 최종 저장 용량이나 필요한 전체 여유 공간이 아닙니다. 변환·생성 파일과 합성 모델·학습 도구의 공간은 별도입니다.

새 호출어는 모두 같은 **챕터 레이아웃**으로 진행합니다. 큰 제목에서 할 일을 확인하고, 작업과 화면 이동은 하단의 **일시정지·재개**, **이전·다음**을 사용합니다. 필요한 작업이나 검수를 마쳐야 다음으로 이동할 수 있습니다. 왼쪽 색인은 진행한 단계까지 유지되며, 앞 단계로 돌아가도 진행 위치로 바로 이동할 수 있습니다. 양방향 이동 안내는 완전히 나타난 뒤 최소 **0.8초** 유지합니다. 화면과 이동 안내의 등장·퇴장 효과는 각각 **0.15초**입니다. 앞뒤 애니메이션과 서버 준비 시간은 별도이며, 실제 완료 순서에 따라 다음 화면으로 이동합니다. 완료한 화면에는 입력한 호출어·선택한 규모·처리 수량·저장된 판정을 그대로 보여주며, 다시 실행하거나 수정하지 않습니다. 호출어·학습 규모를 제목 아래에 반복 표시하지 않으며, **설정 → 작업한 호출어**, **호출어 입력**, **학습 규모 선택**에서 확인합니다. 합성 목소리 듣기에서는 제목·목소리 선택·재생 바·이동 버튼을 한곳에 모아 보여줍니다. 목소리 선택 버튼과 목록은 하나로 이어져 보입니다. 선택 버튼은 재생 박스와 같은 바탕색이며, 마우스를 올리거나 키보드로 선택하면 밝아집니다. 목록은 표시 공간과 위치를 확정한 뒤 나타나며, 주변 요소를 움직이지 않고 내부에서 스크롤합니다. 다른 청취 화면과 같은 스타일의 재생 바로 재생 위치와 음량을 조절합니다. 작은 테두리형 목소리 선택칸 아래에 재생·진행 바·시간을 한 줄로 표시합니다. 목록줄과 재생 바의 폭을 맞추며, 진행 막대는 재생된 구간만 색으로 채웁니다. 재생 버튼으로 현재 음원을 재생·일시정지합니다. 오른쪽 스피커 버튼은 음소거를 켜고 끄며, 바로 옆의 작은 막대로 음량을 조절합니다. 별도의 음량·재생 메뉴는 표시하지 않습니다. 듣기 화면의 폭과 컨트롤 크기는 준비 화면과 비슷하게 맞춥니다. 목록 버튼과 재생 바는 같은 캡슐형 모서리를 사용합니다. 음소거 아이콘을 크게 표시하고, 음량과 재생 위치 막대는 같은 두께·색·원형 손잡이로 통일합니다. 목록의 번호는 자료 구분 바로 옆에 붙이고, 스크롤바는 둥근 경계 안에 배치합니다. 학습·듣기·검수·결과·마이크 화면의 버튼은 글자색을 고정하고 배경색만 0.2초 동안 부드럽게 바꿉니다. 선택·판정·비활성·키보드 포커스 표시는 유지하며, 작업·자료 연결 버튼의 상태와 문구는 실제로 달라질 때만 반영합니다. 목소리 목록을 열거나 음량을 조절해도 제목·이동 버튼의 위치는 유지합니다.

웹 학습의 음성 생성·모델 학습·공통 평가는 **학습 도구 준비에서 저장한 CPU 또는 NVIDIA GPU**를 따릅니다. 성능 평가는 시작부터 재개까지 선택한 장치의 점수로 채점합니다. GPU 평가는 CUDA 실행을 확인한 뒤 배치로 처리합니다. GPU 실행에 실패하면 원인을 표시하고 멈춥니다. 평가 화면에서 완료 수와 진행률을 확인할 수 있습니다.

**자료 다운로드·전처리 → 호출어 사전 생성·검수 → 호출어 음성 생성·발음 검수 → 유사어 음성 생성·발음 검수 → 증강·학습·평가 → 평가 오디오·마이크 시험**이 이어집니다. 검수는 이 화면 안에서 저장하며, 명령이나 파일 경로를 단계마다 다시 입력하지 않습니다. **일시정지**는 현재 단계를 마친 뒤 적용합니다. 서버나 컴퓨터를 다시 켠 뒤 같은 명령으로 열면 저장된 상태에서 이어갈 수 있습니다.

새 모델은 **감지 기준(임계값) 0.5·연속 감지 1회**로 평가를 시작합니다. 공통 평가 후에는 **임계값 0.01–0.99를 0.01 간격으로, 연속 감지 1–6회를 모두 비교**합니다. 다른 추천 조건을 충족하고 **오호출이 시간당 1회 이하**인 설정 중, 모델 비교의 **강한 소음·울림**과 같은 18개 조건에서 평균 감지율이 가장 높은 설정을 모델마다 추천합니다. 보통·강한 울림, SNR 10·5·0 dB, 배경음 3종을 조합하고 각 조건을 같은 비중으로 평균합니다. 상한 이내의 설정이 없으면 다른 추천 조건을 충족한 설정 중 오호출이 가장 적은 값을 추천합니다. 모델 비교에서 **기본 감지 기준**과 **추천 감지 기준**을 전환할 수 있습니다. 조건별 감지율은 **소음별**에서 볼 수 있고, 모델 비교 표의 **추천 감지 기준** 열 제목을 누르면 추천 규칙이 열립니다.

화면에 표시한 공개 자료와 용량을 먼저 확인하세요. 새 웹 프로젝트는 **선택한 규모에 맞춰 자료를 자동 선정·다운로드·전처리**하고, 제공 학습·평가 배경 자료는 자동 검사 후 연결합니다. **기준 목소리 생성과 검수는 별도 화면**입니다. 이후 목소리별 호출어 샘플을 사전 검수하고, 통과한 기준 음원으로 전체 호출어를 생성합니다. **호출어 발음 검수**에서는 본생성 결과 중 목소리별 음원 1개를 듣습니다. 두 검수에서 공통 평가용 30개를 포함해 **동작 확인용 50개 / 시험 모델용 130개 / 상용 모델용 530개**를 확인합니다. 직접 추가한 자료도 검수합니다. 자료가 부족하거나 이용 조건을 확인해야 하면 이유를 표시하고 멈춥니다. 자세한 사용법은 [웹 학습 안내](docs/WEB_GUIDE.md)를 참고하세요.

새 웹 프로젝트는 공개 학습 음원을 **학습에 사용하는 16kHz 모노 PCM16과 동일한 무손실 FLAC**으로 보관합니다. 새 대규모 비호출 원본과 중복 WAV만 검증 후 정리하며, 기존 자료·공유 기본 묶음·생성 TTS·평가 WAV는 보존합니다. FMA 음악은 한 곡씩 변환·검증하면서 다음 곡 1개만 미리 받습니다. **학습부터 독립 최종 평가까지 필요한 총 저장 용량은 아직 확정되지 않았습니다.** 항목별 참고 계산과 미확정 항목은 [저장 방식과 용량 계산](docs/STORAGE_POLICY.md#상용-모델용-저장-용량-계산)에 정리했습니다.

세 학습 규모 모두 **같은 공통 평가 기준**을 사용합니다. 한국어 대화·인터뷰·낭독, 다른 언어, 음악·환경·전자음의 **일곱 범주·비호출 30시간**으로 통일하고, 평가 음색 30계열·호출 원본 2,000개로 **소음·잔향을 포함한 48,000회 호출 시험**을 구성합니다. 잔향을 추가하지 않은 32,000회와, 같은 대표 원본 500개에 두 강도의 잔향을 적용한 16,000회를 구분해 보고합니다. 같은 배경 자료를 호출어에 섞거나 단독으로 재생해 감지율과 오호출을 확인합니다. 공통 평가 결과와 과거에 보관한 독립 최종 평가 결과는 구분합니다. [평가 자료 안내](docs/DATASETS.md#성능-평가용-배경-음원)를 참고하세요.

## 학습 데이터 준비

### 필요한 학습 자료

학습에는 다음 자료가 필요합니다. **새 호출어 음성은 Qwen TTS(음성 합성 모델)로 호출어만 단독으로 생성**하며, 나머지 공개 자료는 여러 호출어 학습에 재사용할 수 있습니다.

| 자료 | 역할 |
| --- | --- |
| 호출어 음성(Positive) | 모델이 인식해야 할 한국어 호출어 |
| 일반 비호출 자료(Negative) | 호출어가 아닌 대화·음악·환경음으로 오호출을 줄이는 학습 자료 |
| 한국어 비호출 자료 | 한국어 대화·방송·보컬 음성으로 한국어 사용 환경의 오호출을 줄이는 학습 자료 |
| 유사어 자료(Hard Negative) | 호출어와 발음이 비슷한 다른 표현으로 오인식을 줄이는 별도 비호출 학습 자료 |
| 소음 증강 재료 | 호출어와 일반 음성에 섞는 환경음·음악·말소리. 비호출 원본 오디오도 재사용 가능 |
| 잔향 자료(RIR) | 방이나 공간에 따른 울림을 재현하는 재료 |

### 학습 규모 선택

준비할 자료의 양과 학습 작업량을 먼저 정하세요. 아래 표는 모델의 목적에 맞추어 임의대로 정한 설정 예시입니다. 아래 설정값은 최적값으로 입증된 수치는 아니며 모델 학습 후에 결과물에 따라 설정값을 조정하여 더 좋은 결과물을 얻을 수 있습니다. 웹의 **학습 규모 선택**에서 세 단계 중 하나를 고릅니다.

| 선택 항목 | 동작 확인용 | 시험 모델용 | 상용 모델용 |
| --- | ---: | ---: | ---: |
| 호출어 TTS 원본 수 | 1,000개 | 20,000개 | 100,000개 |
| 학습용 기준 목소리 | 20개 | 100개 | 500개 |
| 유사어 한 문구당 음원 수 | 20개 | 100개 | 500개 |
| 원본당 증강 횟수 | 1회(R1) | 3회(R3) | 5회(R5) |
| 모델당 학습량 | 10,000회 | 50,000회 | 100,000회 |
| 일반 비호출 자료 | 2,000시간 | 2,000시간 | 3,500시간 |
| 한국어 비호출 자료 | 1시간 | 500시간 | 1,500시간 |
| 소음 증강 재료 | AudioSet 일부 + FMA 음악 1시간 | AudioSet 일부 + FMA 음악 1시간 | 비호출 자료 재사용 |
| 잔향 증강 재료 | MIT RIR | MIT RIR | MIT RIR |

기준 목소리는 호출어 음성을 만들 때 따라 할 합성 목소리입니다. 선택한 수량 안에서 **성별·연령·음색·말투·발성 강도를 가능한 고르게 배분**하고, 속도와 억양도 분산합니다. 연령은 아동·청소년·젊은 성인·중년·고령으로 나눕니다. **공통 평가용 30개는 학습용과 분리**하며 같은 방식으로 구성합니다. 목소리 수는 시작값이며, 공식 권장량이나 검증된 최적값은 아닙니다.

**유사어 문구 수는 사용자가 정합니다.** 각 문구를 학습용 목소리마다 한 번씩 생성하며, 전체 유사어 음원 수는 **문구 수 × 문구당 음원 수**입니다. 문구당 20·100·500개는 이 라이브러리의 시작값이며, 공식 권장량이나 검증된 최적값은 아닙니다. 기존에 생성한 음원과 검수 기록은 유지합니다.

새 웹 학습은 **유사어 음성 생성**에서 전체 음원을 생성하고 자동 검사합니다. **유사어 발음 검수**에서 문구마다 대표 음원 1개를 듣습니다. 동작 확인용에서 여섯 문구를 입력하면 전체 120개를 생성한 뒤 대표 음원 6개를 검수합니다. 제외한 문구의 음원은 학습 목록에서 빠지며, **유사어 전체 듣기**에서 생성한 음원을 들을 수 있습니다.

AudioSet은 openWakeWord 공식 자동 학습 예제와 같은 균형 학습 세트의 09번 묶음 `bal_train09.tar`에서 **음원 685개**를 가져옵니다. FMA 음악 1시간도 같은 예제의 구성입니다. 잔향 재료는 세 단계 모두 **MIT RIR 16 kHz WAV 270개**를 사용합니다. 출처와 준비 범위는 [증강 재료 안내](docs/DATASETS.md#공식-자동-학습-예제의-증강-재료)를 참고하세요.

상용 모델용은 학습용 일반·한국어 비호출 자료의 **원본 오디오를 소음 증강에도 재사용**합니다. 소음 전용 자료를 별도로 내려받지 않으며, 원본 없는 특징 자료와 평가용 음원은 재사용 대상에서 제외합니다.

상용 모델용의 일반 3,500시간은 **AudioSet 생활·환경·말소리 혼합 1,500시간 / MLS 다국어 낭독 1,500시간 / FMA full 음악·보컬·연주곡 500시간**, 한국어 1,500시간은 **YODAS2 한국어 웹 음성**으로 계획합니다. FMA full은 전체 ZIP 대신 **필요한 곡만 원본 MP3로 선택 다운로드**합니다. 새 상용 웹 프로젝트는 정상 변환·PCM 검증을 마친 새 MP3만 정리하며, 품질 검사에서 거부한 원곡은 보존합니다. 다운로드와 연결 방법은 [상용 비호출 구성](docs/DATASETS.md#상용-모델용-비호출-구성)을 참고하세요. 이 수치는 준비 목표이며 다운로드·검수 완료량이 아닙니다.

동작 확인용·시험 모델용의 일반 비호출은 [openWakeWord 공개 특징 자료](https://huggingface.co/datasets/davidscripka/openwakeword_features)의 약 2,000시간짜리 파일을 사용합니다. **원본 오디오가 아니라, 학습에 바로 넣을 수 있도록 미리 숫자로 변환한 자료**이며 웹에서 자동으로 준비합니다.

<details>
<summary>자료 규모와 증강 횟수 읽는 법</summary>

표의 시간은 학습 전에 준비할 자료의 양입니다. 시험 모델용은 일반 2,000시간 + 한국어 500시간, 상용 모델용은 **일반 3,500시간 + 한국어 1,500시간 = 총 5,000시간(70:30)**입니다. 자료 시간과 별개로 세 단계의 일반·한국어 비호출 배치는 **75:25**를 유지합니다. 한국어 비중과 자료 시간은 이 라이브러리에서 선택한 구성으로, 공식에서 제시한 최적값은 아닙니다.

호출어 원본 수는 **증강 전 TTS 수량**입니다.

**R1·R3·R5는 원본 한 개당 각각 1·3·5개의 변형을 만드는 설정**입니다. 원본 100,000개라면 R1은 100,000개, R5는 500,000개의 호출어 학습 자료를 준비합니다. 증강 횟수를 늘려도 매회 사용하는 자료 수와 모델당 학습량은 그대로이며, 더 다양한 변형 중에서 자료를 뽑게 됩니다.

비호출 자료는 **시간과 종류의 다양성**으로 관리합니다. 소음 증강에는 AudioSet·음악 같은 원본 오디오를 사용하며, 일반·한국어 비호출 자료의 **원본 오디오도 재사용할 수 있습니다.** 같은 자료를 두 용도로 사용해도 비호출 총시간에 다시 더하지 않습니다. 원본 오디오 없이 사전 계산된 특징만 받은 자료는 비호출 학습에만 사용합니다. 잔향(RIR)은 서로 다른 공간의 자료를 연결합니다.

목표 시간은 이미 준비한 자료를 재사용할 때도 적용합니다. 웹은 선택한 규모에 맞춰 자료를 준비합니다. 자료 출처와 재사용 기준은 [데이터 준비 안내](docs/DATASETS.md)에 있습니다. 정식 학습 전에는 검사와 사용 조건 확인을 거쳐 연결한 비호출 시간이 목표를 충족했는지 확인합니다. 소음 증강 재료는 별도 비호출 배치 항목으로 추가하지 않습니다.

**모델 구조·학습 방법의 설정 비교와 데이터량의 최적화는 구분합니다.** 위의 호출어 수와 비호출 시간은 최적량이 입증된 값이 아닙니다. 새 호출어의 데이터량은 공식 안내와 공개 학습 사례를 참고해 선택합니다. 근거와 비교 방법은 [데이터량 선정 기준](plan.md#데이터량의-근거와-선택-원칙)에 있습니다.

작업량을 줄여도 Qwen 모델과 공개 사전 계산 자료의 최초 다운로드 크기는 줄어들지 않습니다.

</details>

새 동작 확인용·시험 모델용은 공식 예제의 **같은 음악 120곡과 목록 파일만 선택 다운로드**합니다. 음악·목록 전송 상한은 합계 약 **116MiB**이며, 기존 전체 ZIP 두 개 약 **7.49GiB**를 모두 받지 않습니다. 일반 비호출·한국어·공통 평가 자료는 별도로 필요합니다. 원본 음질·곡 구성은 유지하고 곡별 검증과 이어받기를 지원합니다.

미리 확정된 학습·평가 자료는 **하나의 다운로드 대기열**에서 받고, 전송 상태에 맞춰 동시 처리 수를 자동 조절합니다. 화면에서 자료별 대기·다운로드·검사·완료 상태를 확인할 수 있습니다. 추가 선정이 필요한 대용량 원본은 목록과 저장 공간이 준비된 뒤 이어서 받으며, 파일별 이어받기·해시 검증·이후 처리 순서는 유지합니다. 자세한 범위와 수동 설정은 [웹 학습 안내](docs/WEB_GUIDE.md#다운로드-속도와-동시-처리)를 참고하세요.

## 호출어 학습 시작

**설정 → 새 호출어 생성**에서 시작하고, 이미 진행한 작업은 **설정 → 작업한 호출어**에서 엽니다. **학습 도구 준비**에서 CPU 또는 NVIDIA GPU를 선택하면 웹에서 음성 생성·학습·평가에 필요한 도구를 준비합니다. [웹 학습 안내](docs/WEB_GUIDE.md) · [학습 가이드](docs/LIBRARY_GUIDE.md)

설치 확인은 `koww check`(`koww doctor`)로 실행합니다. 기존 모델의 WAV 시험에는 `koww infer`, 마이크 시험에는 `koww mic`를 사용합니다. 동봉 모델의 검증과 예시 시험은 `koww sample`과 `koww demo`로 실행합니다. 세부 인자는 `koww --help`에서 확인합니다.

## 마이크로 모델 시험

기본 설치만 마쳤다면 다음 명령으로 동봉된 ‘춘식아’ 모델을 시험할 수 있습니다. 추가 패키지는 필요하지 않습니다.

```powershell
koww mic
```

[http://127.0.0.1:8792/](http://127.0.0.1:8792/)을 열어 **연결**로 마이크 권한을 허용합니다. 마이크를 선택한 뒤 **시험 시작**을 누르고 준비 표시가 끝나면(기본 2초) 호출어를 말합니다. 각 모델과 앙상블의 점수·감지 여부·감지 횟수를 확인할 수 있습니다.

직접 학습한 모델 묶음을 시험하려면 경로를 지정합니다.

```powershell
koww mic --bundle models/model_0001/models/studio_bundle
```

감지 기준을 조절해도 그 시험에만 적용됩니다. 마이크 음성은 파일로 저장하거나 학습에 사용하지 않습니다. **중지**를 누르면 마이크 입력을 종료합니다. 서버를 유지하려면 터미널을 열어 두고, 종료할 때는 Ctrl+C를 누르세요. 상세 사용법은 [마이크 시험 안내](docs/LIBRARY_GUIDE.md#마이크로-모델-시험하기)에 있습니다.

## Python에서 모델 사용

```python
from korean_openwakeword import WakeWordDetector

detector = WakeWordDetector()  # 동봉된 ‘춘식아’ 모델 사용
result = detector.predict_file("test.wav")
print(result["events"])  # 호출어가 감지된 시점 목록
```

입력 파일은 **16kHz·모노·16비트 PCM 형식의 WAV**를 사용합니다. 기본 설정의 초기 준비 구간은 2초이므로 호출어가 그 이후에 나오도록 준비하세요. 직접 학습한 모델 사용법과 실시간 입력은 [라이브러리 가이드](docs/LIBRARY_GUIDE.md)를 참고하세요.
