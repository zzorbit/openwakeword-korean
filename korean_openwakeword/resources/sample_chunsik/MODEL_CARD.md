# ‘춘식아’ 표본 모델 설명서

제공 모델은 **CNN128 모델 3개의 호출 점수를 평균하는 앙상블**입니다. 음성을 처리하는 공통 모델은 한 번 실행하고, 그 결과를 세 판별기에 전달합니다. R5는 원본 음성마다 5개의 증강 결과를 만드는 학습 설정이며 앙상블 모델 수와는 별개입니다.

새 호출어에는 새 호출어 음성을 생성해 별도의 판별기를 학습합니다.

## 확인된 성능

아래는 **라이브러리에 동봉된 평균 앙상블 한 묶음**의 개발용 평가(Development) 결과입니다. 평가 모델과 동봉 모델의 세 가중치 SHA256 및 실행 설정을 대조했습니다.

| 지표 | 관측 결과 |
| --- | --- |
| 소음 없는 환경(Clean) | 5,000/5,000회 감지, 100% |
| 소음 평균 성공률 | 5,951/6,000회 감지, 99.1833%. 환경음·음악·겹치는 한국어 대화 × SNR20/15/10/5의 균등 평균 |
| 오호출 | 호출어 없는 자료 24.0329시간에서 2회, 0.0832회/시간 |
| 한국어 대화가 겹치는 SNR5 | 460/500회 감지, 92% |

이 표는 모델과 설정을 고를 때 사용한 합성 호출 음성의 개발용 자료 결과입니다. **별도 100시간 최종 평가와 실제 다수 화자 평가는 완료하지 않았습니다.**

같은 설정으로 독립 학습한 앙상블 3묶음의 소음 성공률은 99.1833% / 98.9833% / 99.1667%이며 평균은 99.1111%입니다. 동일한 24.0329시간 비호출 자료에서 각각 2 / 2 / 1회 오호출했습니다. README에는 이 세 묶음의 평균 대신 실제 동봉된 첫 번째 묶음의 수치를 표시합니다. 같은 자료를 반복 평가한 시간은 합산하지 않습니다.

## 파일과 이용조건

- [manifest.json](manifest.json): 모델·공통 음성 처리 파일, 실행 설정, 파일 해시
- [audio_manifest.json](audio_manifest.json): 동봉 오디오의 원본·호출 경계·해시
- [AUDIO_SOURCES.json](AUDIO_SOURCES.json): 동봉 배경음의 출처
- [이용조건·출처](THIRD_PARTY_NOTICES.md): 모델·음원의 조건과 원문 안내

모델과 음원의 이용조건은 코드 라이선스와 구분합니다. 상위 openWakeWord 출처는 [공식 저장소](https://github.com/dscripka/openWakeWord)이며, Qwen·공개 데이터셋의 조건도 유지합니다.
